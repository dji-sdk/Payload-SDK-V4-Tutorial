This section introduces the payload development kits and hardware platforms supported by the Payload SDK, helping developers understand the port types, hardware specifications, compatible aircraft models, and purchase methods of different development kits. Developers can select the appropriate development kit based on the target flight platform, payload form, communication port, and power supply requirements for payload solution design, hardware integration, and development debugging.

:::tip Note:
Currently, the Payload SDK only supports the **Matrice 5TD** to access payload devices via the **E-Port V3 port**. For development and debugging, you can use the **E-Port V3 development board + E-Port V3 coaxial cable**. If new aircraft models, ports, or development kits are supported later, this document will be updated accordingly.
:::

## Purchase Development Kit

#### E-Port V3 Development Kit
The E-Port V3 Development Kit is used to convert the E-Port V3 of the Matrice 5TD aircraft into various standard hardware ports, and provides an onboard MCU, making it convenient for developers to connect hardware devices and conduct SDK development and debugging, achieving a ready-to-use experience right out of the box. This kit is also compatible with the E-Port V2 port and can switch between E-Port V2 and E-Port V3 port modes via a toggle switch on the development board.

The E-Port V3 development board features a GD32F527ZMT7 MCU with 8 MB of external SDRAM. Detailed device specifications and technical documentation are available on the <font color=#1fA3f6><a href="https://www.gigadevice.com.cn/product/mcu/mcus-product-selector/gd32f527zmt7" target="_blank">GigaDevice official website</a></font>.

#### E-Port V3 Coaxial Cable

Used to convert the E-Port V3 port on the Matrice 5TD flight platform into a coaxial cable port. Developers can design payload hardware ports according to the coaxial cable pin definitions.
