## Development and Mass Production

### Preparation Before Development

Before developing a payload device with PSDK, it is recommended to first learn the basic knowledge required for developing payload devices, and understand the functions of PSDK and the standards that payload devices must meet.

* Learn the basic knowledge and control principles of drones: such as pitch, yaw, roll, and ascent/descent.
* Review DJI's <a href="../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html" target="_blank" rel="noopener noreferrer">payload standards</a>.

### Start Developing the Payload Device

When developing a payload device with PSDK, **please correctly connect** the selected development kit, third-party development board, and DJI drone, **correctly configure** the payload device development environment, correctly import PSDK, and complete the initialization configuration.

* Before developing a payload device with PSDK, please first read the content in the <a href="./safety-information.html" target="_blank" rel="noopener noreferrer">Safety Information</a> to avoid damaging the payload device or drone due to improper operation.
* Connect the drone, development kit, third-party development board, and computer.
  * <a href="../payload-quick-start/configure-the-hardware-environment/device-connect.html" target="_blank" rel="noopener noreferrer">Payload Development Hardware Connection</a>
* Configure the development environment and prepare the relevant toolchains and libraries.
  * <a href="../payload-quick-start/config-develop-environment.html" target="_blank" rel="noopener noreferrer">Configure Development Environment</a>
* Import PSDK and complete initialization.
  * <a href="../payload-quick-start/getting-started-with-psdk.html" target="_blank" rel="noopener noreferrer">Importing PSDK for Payload Development</a>

### Develop a Fully Functional Payload Device

* Develop the payload device according to the <a href="../function-set/access-authentication.html" target="_blank" rel="noopener noreferrer">Function Set</a> and <a href="../api-reference/api-access-authentication.html" target="_blank" rel="noopener noreferrer">Protocol Reference</a>.
* Use tools such as <a href="https://www.dji.com/cn/downloads/softwares/assistant-dji-2-for-matrice" target="_blank" rel="noopener noreferrer">DJI Assistant 2</a> to debug the payload device, improve its functionality, and enhance its performance.

### Apply for Payload Certification and Enable Mass Production

Go to the DJI Developer website and click Personal Center -> Application Details -> Application Certification.

:::warning Warning:
* A single PSDK APP application authorization can bind a maximum of 20 payloads. This limit will be lifted after applying to enable the mass production feature.
* Starting from **January 1, 2025**, newly registered PSDK applications are in development mode by default. Ecosystem payloads that need to complete device binding are subject to this quantity limit in development mode; ecosystem payloads that do not involve the binding process are not restricted.
:::

## Business Cooperation

DJI adheres to the principle of **openness and mutual benefit**, and provides developers with technical support, payload testing, channel recommendations, DJI ecosystem promotion, and other services. DJI works with developers and partners to build a sustainable application ecosystem.

* If a payload device developed by a partner passes DJI's payload testing, the payload device will be recommended by DJI to third-party partners.
* If a partner's payload device passes testing by a third-party professional organization, DJI will carry out more in-depth cooperation with the partner after signing a cooperation agreement, such as recommending the partner's payload device to <a href="https://www.dji.com/cn/products/enterprise#partner-payloads" target="_blank" rel="noopener noreferrer">global users</a>. For more cooperation matters, please <a href="mailto:dev@dji.com">contact us</a>.
