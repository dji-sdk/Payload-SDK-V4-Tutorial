This document systematically introduces the core product capabilities, supported ports, and model compatibility of the DJI Payload SDK. It assists developers in quickly understanding and evaluating the PSDK's applicability across different application scenarios from dimensions such as aircraft platforms, port types, and functional capabilities. This provides a reference basis for payload solution selection and system design.
