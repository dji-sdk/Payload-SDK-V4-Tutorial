## E-Port V3 Port

The Matrice 5TD aircraft body provides an E-Port V3 port for connecting third-party PSDK payload devices.

<div>
<div align=center>
<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk-iot/demo/EPort_V3_Port.png" style="width:80%"/>
<div style="text-align: center"><p>Figure. Matrice 5TD E-Port V3 Port</p></div>
</div></div>

All E-Port V3 ports on the Matrice 5TD support connecting payload devices. E1 is the high-speed port (supports USB 3.0), while E2/E3 are low-speed ports (support USB 2.0).

:::tip Note:
- After power-on, the payload port of the Matrice 5TD first outputs 5V low voltage. Once the aircraft identifies that a third-party payload is connected, it automatically outputs high voltage (15V-25.8V), and developers do not need to request high voltage manually. The aircraft first waits for the payload to complete USB enumeration; if no enumeration is detected after approximately 6 s, it queries the SDK certified chip instead. For details, see <a href="./payload-develop-criterion.html#high-voltage-output-trigger-mechanism" target="_blank" rel="noopener noreferrer">High-Voltage Output Trigger Mechanism</a>.
- Currently, only one USB enumeration mode is supported: the external device implements USB RNDIS mode, with VID:PID set to `2CA3:F004`.
:::

### E-Port V3 Development Kit

The E-Port V3 development board has a built-in MCU, MCU model: GD32F527ZMT7, with external SDRAM 8 MB. MCU device specifications and technical documents are available from the [GD32 official website](https://www.gd32mcu.com/en/product). This development board is also compatible with the E-Port V2 port and can switch between E-Port V2 or E-Port V3 port mode via a toggle switch.

The silkscreen of the Onboard Authentication Chip Enable Switch is JM. This switch is used to select the authentication chip source. By default, it is set to N, which uses the authentication chip built into the E-Port V3 coaxial cable. When set to Y, the onboard authentication chip on the development board is used, which is applicable when making or verifying a custom cable.
