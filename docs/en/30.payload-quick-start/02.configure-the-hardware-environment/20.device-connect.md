## Matrice 5TD Device Connection

Before starting the device connection of the Matrice 5TD, please read the "Component Names" section in the Matrice 5TD User Manual and pay attention to the introduction of the aircraft components. The Matrice 5TD supports connecting the aircraft to payload devices via the E-Port V3 port.

### Connect Device via E-Port V3 Port

All E-Port V3 ports on the Matrice 5TD support connecting payload devices. E1 is the high-speed port (supports USB 3.0), while E2/E3 are low-speed ports (support USB 2.0). The figure below uses the E3 low-speed port as an example. For high-speed data capabilities, use the E1 high-speed port. For details, see <a href="./drone-port.html#e-port-v3-port" target="_blank" rel="noopener noreferrer">E-Port V3 Port</a>.

Use an E-Port V3 coaxial cable to connect the E-Port V3 development board to the E-Port V3 port on the Matrice 5TD. The specific steps are as follows:

1. Set the E-Port V2/V3 toggle switch on the E-Port V3 development board to the "E-PORT V3" side.
2. Set the ENABLE switch on the E-Port V3 development board to "ON", and set the SWITCH to the "ONBOARD" side (use "ONBOARD" for onboard GD32 development, and "EXPAND" for an external development board; see the description below for details).
3. Use an E-Port V3 coaxial cable to connect the E-Port V3 development board to the E-Port V3 port on the Matrice 5TD aircraft body.
4. Power on the entire aircraft and check whether the green power indicator on the E-Port V3 development board is lit.

After completing the connection following the steps above, users can develop with PSDK directly using the onboard GD32 on the E-Port V3 development board, or set the SWITCH to the "EXPAND" side and connect a third-party development board via the USB port on the E-Port V3 development board for development.
