### Resource Usage Comparison
#### Linux
Using Manifold 3 to run the Linux platform PSDK sample program, the resource usage during program runtime is as follows:
* Stack: approximately 135,168 bytes
* Heap: approximately 270,336 bytes
* Text segment: 1,409,889 bytes
* Data segment: 19,532 bytes
* Bss segment: 20,344 bytes
* CPU usage: 7.2 %

#### RTOS
Using GD32F527ZMT7 to run the RTOS platform PSDK sample program, the resource usage during program runtime is as follows:
* Text segment: 281,880 bytes
* Data segment: 892 bytes
* Bss segment: 521,176 bytes
* RAM usage: 142,000 bytes
* CPU usage: 24%

## Configure the Environment
Please read the corresponding subsection according to the selected system platform.

### Configure the Linux Development Environment
The Payload SDK is based on the **MQTT protocol**, providing C client code, and communicating with the flight platform through an MQTT broker. Before developing a payload device, please first prepare the following tools and dependencies.

#### Install the Build Tools

| Tool | Minimum Version | Purpose | Ubuntu / Debian Installation Command |
|:---|:---|:---|:---|
| GCC host compiler | - | Build the native host demo | `sudo apt install build-essential` |
| aarch64-linux-gnu-gcc | 9 | Cross-compile the arm64 payload demo | `sudo apt install gcc-aarch64-linux-gnu` |
| CMake | 3.13 | Build system | `sudo apt install cmake` |
| OpenSSL headers | - | TLS and HMAC (host headers are common across architectures) | `sudo apt install libssl-dev` |
| Mosquitto headers | - | MQTT communication (transport layer) | `sudo apt install libmosquitto-dev` |
| cJSON headers | - | JSON encoding/decoding | `sudo apt install libcjson-dev` |

> Note:
> - The repository no longer ships vendored precompiled libraries with the package. During cross-compilation, the host needs to provide the OpenSSL / mosquitto / cJSON header files; the runtime libraries of the corresponding architecture are then installed on the target machine at runtime.
> - FFmpeg is no longer a required dependency for the samples; for speaker/media-related functions, please supplement according to the specific business documentation.

### Configure the RTOS Development Environment

The GD32F527 is based on the Cortex-M33 core and needs to be compiled with ARM Compiler 6 (Armclang); ARM Compiler 5 (Armcc) is not supported.

Among them, the C compiler is the core tool, and it is recommended to use Armclang.exe V6.12. The complete development environment configuration recommendations are as follows:

| Item | Version |
|:---|:---|
| Keil MDK-ARM | 5.27.1 |
| C Compiler | Armclang.exe V6.12 |
| Assembler | Armasm.exe V6.12 (integrated with Armclang) |
| Linker | Armlink.exe V6.12 |
| CMSIS Core | 5.5.1 |
| Device Family Pack | GigaDevice.GD32F527_DFP 1.4.0 |

After installing [Keil MDK](http://www2.keil.com/mdk5/), activate the software, and manually download and install the latest GD32F527 AddOn package from the [GigaDevice official website](https://www.gd32mcu.com/cn/download?kw=f527&lan=cn) to complete the configuration of the Device Family Pack listed in the table above.
