This section defines the MQTT interface of the aircraft information feature, covering the MQTT payload structure and field descriptions of the `aircraft_info_push` event.

:::tip Note:
- The C interfaces in PSDK encapsulate the MQTT protocol described in this section. When developing with PSDK, you do not need to handle MQTT messages directly. Refer to these protocol definitions only if you need to implement the protocol yourself or debug and verify the underlying messages. For the feature overview and C interface examples, see <a href="../function-set/aircraft-information.html" target="_blank" rel="noopener noreferrer">Function Set - Aircraft Information</a>.
- Before using this feature, the payload device must first complete access and authentication. For the access protocol, see <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">Access and Authentication</a>.
:::

## Protocol Description

The topics involved in the interface are as follows:

| Type | Direction | Topic |
|:---|:---|:---|
| osd push | Aircraft → Payload | thing/product/{client_id}/osd |

- `{client_id}` is the payload device serial number.
- **QoS**: 0.

The interfaces supported by this module are as follows:

| method | Type | Purpose | Corresponding C interface |
|:---|:---|:---|:---|
| aircraft_info_push | osd | The aircraft periodically pushes the aircraft model, firmware version, App information, and device list | Received after subscribing with sample_aircraft_info_start() |

## Common Parameters

### Push Parameters

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| seq | integer | Yes | Message sequence number. |
| method | string | Yes | Fixed as `aircraft_info_push`. |
| data | object | Yes | Service data body; see the field descriptions of each interface. |

## aircraft_info_push Push

After the aircraft connects to the MQTT server, it periodically pushes aircraft information, carrying the aircraft model code, the aircraft firmware version, the language and screen type of the mobile App, and the list of all devices on the aircraft. Based on this, the payload can learn about the flight platform environment it is currently mounted on.

Related feature section: <a href="../function-set/aircraft-information.html#receive-aircraft-information" target="_blank" rel="noopener noreferrer">Receive Aircraft Information</a>.

### Payload Example

- **Topic**: `thing/product/{client_id}/osd`
- **Direction**: Aircraft → Payload
- **QoS**: 0
- **method**: `aircraft_info_push`
- **Corresponding interface**: Passively received after subscribing with `sample_aircraft_info_start()`

```json
{
  "seq": 42,
  "method": "aircraft_info_push",
  "data": {
    "aircraft_type": 0,
    "aircraft_version": "01.02.03.04",
    "mobile_app_info": {
      "language": 0,
      "screen_type": 0
    },
    "devices_info": [
      {
        "device_id": "1ZNBJ1234567890",
        "device_name": "EA710",
        "serial_number": "1ZNBJ1234567890",
        "firmware_version": "1.0.0.0",
        "device_type": 1
      }
    ]
  }
}
```

### Field Description

For the top-level fields, see [Push Parameters](#push-parameters). The `data` fields are described below:

<div class="collapsible" />

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| aircraft_type | integer | Yes | Aircraft model code (a raw integer that can accommodate future new models). |
| aircraft_version | string | Yes | Aircraft firmware version, such as `01.02.03.04`. |
| mobile_app_info | object | Yes | Mobile App information. |
| >>language | integer | Yes | Current system language of the App.<ul><li>0: English</li><li>1: Simplified Chinese</li><li>2: Japanese</li><li>3: French</li></ul> |
| >>screen_type | integer | Yes | Current screen type of the App.<ul><li>0: Large screen</li><li>1: Small screen</li></ul> |
| devices_info | array&lt;object&gt; | Yes | List of devices on the aircraft. |
| >>device_id | string | Yes | Device ID, such as `<client_id>`. |
| >>device_name | string | Yes | Device name. |
| >>serial_number | string | Yes | Serial number. |
| >>firmware_version | string | Yes | Firmware version. |
| >>device_type | integer | Yes | Device category.<ul><li>1: Aircraft</li><li>4: Payload</li></ul> |
