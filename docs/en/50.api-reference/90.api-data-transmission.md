This section defines the MQTT interfaces of the data transmission feature, covering the MQTT payload structures and field descriptions for payload data sending and receiving.

:::tip Note:
- The C interfaces in PSDK encapsulate the MQTT protocol described in this section. When developing with PSDK, you do not need to handle MQTT messages directly. Refer to these protocol definitions only if you need to implement the protocol yourself or debug and verify the underlying messages. For the feature overview and C interface examples, see <a href="../function-set/data-transmission.html" target="_blank" rel="noopener noreferrer">Function Set - Data Transmission</a>.
- Before using this feature, the payload device must first complete Access and Authentication. For the access protocol, see <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">Access and Authentication</a>.
:::

## Protocol Description

The Topics involved in the interfaces are as follows:

| Type | Direction | Topic |
|:---|:---|:---|
| event send | payload → aircraft | `thing/product/{client_id}/events` |
| event receive | aircraft → payload | `thing/product/{client_id}/events` |

- `{client_id}` is the payload device serial number.
- **QoS**: 0.

The interfaces supported by this module are as follows:

| method | Type | Purpose | Corresponding C interface |
|:---|:---|:---|:---|
| `custom_small_data_transmit_req` | event | The payload sends data to a target device | `CustomSmallData_PublishTransmit()` |
| `custom_small_data_transmit_event` | event | The payload receives data sent from other payloads or the cloud | `CustomSmallData_OnTransmitPush()` |

:::warning Warning:
Sending and receiving use different methods: `custom_small_data_transmit_req` for sending, and `custom_small_data_transmit_event` for receiving; the aircraft distinguishes the routing direction accordingly, and they must not be used interchangeably. The event uses fire-and-forget semantics, with no `services_reply` acknowledgment.
:::

## Common Parameters

The following parameters are the top-level common parameters shared by the messages of all data transmission interfaces, and are not listed repeatedly in the field descriptions of each interface.

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| seq | integer | Yes | Message sequence number. |
| method | string | Yes | Method identifier; for values, see each interface description. |
| data | object | Yes | Service data body. |

## Send Data

The payload sends a piece of small data to a specified target device. The data is routed and forwarded to the target device by the aircraft.

Related feature section: <a href="../function-set/data-transmission.html#send-data" target="_blank" rel="noopener noreferrer">Send Data</a>.

### Payload Example

- **Topic**: `thing/product/{client_id}/events`
- **Direction**: payload → aircraft
- **QoS**: 0
- **method**: `custom_small_data_transmit_req`
- **Corresponding interface**: `CustomSmallData_PublishTransmit()`

```json
{
  "seq": 1,
  "method": "custom_small_data_transmit_req",
  "data": {
    "target": 15,
    "payload": "aGVsbG8gY2xvdWQ="
  }
}
```

### Field Description

For the top-level fields, see [Common Parameters](#common-parameters). The `data` fields are described as follows:

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| target | integer | Yes | Target device channel address.<ul><li>1: payload position 1</li><li>2: payload position 2</li><li>3: payload position 3</li><li>15: cloud</li></ul> |
| payload | string | Yes | Transparent transmission data, a string of the raw bytes Base64-encoded, up to 256 bytes after decoding. |

## Receive Data

Data sent from other payloads or the cloud is forwarded by the aircraft and pushed to the payload.

Related feature section: <a href="../function-set/data-transmission.html#receive-data" target="_blank" rel="noopener noreferrer">Receive Data</a>.

### Payload Example

- **Topic**: `thing/product/{client_id}/events`
- **Direction**: aircraft → payload
- **QoS**: 0
- **method**: `custom_small_data_transmit_event`
- **Corresponding interface**: `CustomSmallData_OnTransmitPush()`

```json
{
  "seq": 2,
  "method": "custom_small_data_transmit_event",
  "data": {
    "source": 1,
    "payload": "cnRvcyBhY2sgIzA="
  }
}
```

### Field Description

For the top-level fields, see [Common Parameters](#common-parameters). The `data` fields are described as follows:

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| source | integer | Yes | Data source, i.e., the device that sent this transparent transmission data.<ul><li>1: payload position 1</li><li>2: payload position 2</li><li>3: payload position 3</li><li>15: cloud</li></ul> |
| payload | string | Yes | Transparent transmission data, a string of the raw bytes Base64-encoded, up to 256 bytes after decoding. |
