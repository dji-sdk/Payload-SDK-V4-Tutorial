## Payload SDK V4.0.0 Release Notes

### Release Date

2026-11-05

### Version Description

Payload SDK V4.0.0 is the first official release of the V4 series. It adopts an open implementation based on the MQTT protocol and is provided in source-code form; the payload device completes online authentication, control interaction, data reporting, data transmission, and the upgrade process through standard MQTT channels.

### Feature Support List

This version already supports the following features:

- Binding Status Notification: Obtain the binding and unbinding status of the payload on the platform side in real time.
- Aircraft Information: Query information such as the aircraft model, firmware version, and payload mount position.
- Data Subscription: Subscribe on demand to flight status data such as the aircraft attitude, position, velocity, and battery level.
- Local Upgrade: Initiated by the aircraft; the firmware is transferred over HTTP and the upgrade progress is reported via MQTT.
- Custom Widget: Dynamically present the payload's custom interactive widgets on the App side.
- Speaker Widget: Control the broadcast content and volume of speaker-type payloads.
- GEO Caging: Trigger the flight platform to stop the propellers via a hardware PWM signal in abnormal scenarios.
- Time Synchronization: Synchronize the payload's local time with the aircraft's system time.
- Data Transmission: Perform bidirectional custom data transmission between the payload and the platform.
- Power Management: Coordinate the power supply state between the payload and the aircraft, and respond to power-off notifications issued by the aircraft.
- SDK Interconnection: Implement data interaction between the payload and other SDK devices.
