## 概述

机型信息（Aircraft Information）用于负载侧了解当前挂载飞机的型号、固件版本、移动端 App 配置及机上设备清单。设备连接 MQTT 服务器后，飞机会周期推送 `aircraft_info_push` 消息；负载通过监听该推送，在不发起任何请求的前提下被动获取飞行平台的上下文信息。

负载可根据机型（`aircraft_type`）决策是否开启特定功能，也可依据移动端 App 语言（`language`）与屏幕类型（`screen_type`）返回对应的控件配置文件。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-aircraft-information.html" target="_blank" rel="noopener noreferrer">协议参考-机型信息</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 监听启停机制

机型信息监听通过 `ThingModelClientSession_AddListener()` 注册，不新建 MQTT 连接。监听器收到消息后先校验消息类型，仅在消息类型为 `aircraft_info_push` 时进行 JSON 解码，以减少对消息分发流程的影响。

监听启停状态（enabled）按以下优先级生效：
1. 环境变量 `THING_MODEL_AIRCRAFT_INFO`（`0`/`off`/`false` 关闭，其余非空开启）
2. 编译期宏 `SAMPLE_AIRCRAFT_INFO_DEFAULT`（默认 `1` 即开启）
3. 运行期 `sample_aircraft_info_set_enabled()` 切换（下次调用 `sample_aircraft_info_start()` 时生效）

:::warning 注意：
监听器回调运行在后台消息分发线程上。回调内不得注销监听器或销毁会话，否则会因内部锁竞争产生死锁；也不应调用同步接口，否则会阻塞分发线程直至超时，导致本次同步调用的响应无法分发。耗时逻辑应转交其他线程处理。
:::

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 启动监听

在建立 MQTT 会话后调用 `sample_aircraft_info_start()`，注册监听器并订阅机型信息推送。监听状态为关闭时，接口返回 `0`，不注册监听器或订阅 Topic。该接口可重复调用，重复调用不会重复注册监听器。对应的 MQTT 协议见 <a href="../api-reference/api-aircraft-information.html#aircraft-info-push-推送" target="_blank" rel="noopener noreferrer">aircraft_info_push 推送</a>。

```c
ThingModelClientSession_t *s = sample_session_open(&cfg);
if (!s) { /* 处理连接失败 */ return -1; }

/* 注册机型信息监听；enabled=false 时不订阅 Topic */
sample_aircraft_info_start(s);
```

:::tip 说明：
`sample_aircraft_info_start()` 内部调用 `ThingModelClientSession_Subscribe()` 订阅 `thing/product/{sn}/osd`。`auto_reconnect` 开启时，断线重连后会自动重新订阅。
:::

### 接收机型信息

监听器识别到 `aircraft_info_push` 后，调用解析函数 `AircraftInfoJson_DecodeAircraftInfoPush()` 解析 JSON payload，获取机型、固件版本、App 信息及设备清单。

```c
/* 在会话监听器回调中（参考 sample_aircraft_info.c 内部实现）*/
static void on_session_msg(void *user, const char *topic,
                           const char *payload, size_t len)
{
    /* 仅处理机型信息推送使用的通道 */
    if (!strstr(topic, "osd"))                                 return;
    /* 仅在收到目标消息时解码 */
    if (!payload_contains(payload, len, "aircraft_info_push")) return;

    T_AircraftInfoPush a;
    AircraftInfo_InitAircraftInfoPush(&a);
    if (AircraftInfoJson_DecodeAircraftInfoPush(payload, &a) == THING_MODEL_RC_OK) {
        printf("[aircraft_info] 机型=%d 固件=%s App{lang=%d screen=%d} 设备数=%zu\n",
               a.aircraft_type,
               a.aircraft_version ? a.aircraft_version : "-",
               a.mobile_app_info.language,
               a.mobile_app_info.screen_type,
               a.devices_info_count);

        for (size_t i = 0; i < a.devices_info_count; i++) {
            const T_AircraftDeviceInfo *d = &a.devices_info[i];
            printf("[aircraft_info]   dev[%zu]: id=%s name=%s sn=%s fw=%s type=%d\n",
                   i,
                   d->device_id        ? d->device_id        : "-",
                   d->device_name      ? d->device_name      : "-",
                   d->serial_number    ? d->serial_number    : "-",
                   d->firmware_version ? d->firmware_version : "-",
                   d->device_type);
        }
    }
    AircraftInfo_FreeAircraftInfoPush(&a);
}
```

:::tip 说明：
可传入整条 payload；解码器 `AircraftInfoJson_DecodeAircraftInfoPush()` 会读取外层 `data` 字段。解码完成后须调用 `AircraftInfo_FreeAircraftInfoPush()` 释放动态分配的字符串字段（`aircraft_version`、`device_id` 等）。
:::

推送数据结构 `T_AircraftInfoPush` 的字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| aircraft_type | int32_t | 机型代号（原始整数，容纳未来新增值） |
| aircraft_version | char * | 飞机固件版本字符串，如 "01.02.03.04" |
| mobile_app_info | T_MobileAppInfo | 移动端 App 信息，见下表 |
| devices_info | T_AircraftDeviceInfo * | 机上设备清单（动态数组） |
| devices_info_count | size_t | 设备清单元素个数 |

App 信息结构 `T_MobileAppInfo` 的字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| language | int32_t | App 系统语言。<ul><li>0：英语</li><li>1：中文简体</li><li>2：日语</li><li>3：法语</li></ul> |
| screen_type | int32_t | App 屏幕类型。<ul><li>0：大屏</li><li>1：小屏</li></ul> |

设备信息结构 `T_AircraftDeviceInfo` 的字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| device_id | char * | 设备 ID，如 &lt;client_id&gt; |
| device_name | char * | 设备名称 |
| serial_number | char * | 序列号 |
| firmware_version | char * | 固件版本字符串 |
| device_type | int32_t | 设备类别。<ul><li>1：飞机</li><li>4：负载</li></ul> |

### 切换监听状态

运行期间可通过 `sample_aircraft_info_set_enabled()` 关闭或重新开启机型信息监听。设置后在下次调用 `sample_aircraft_info_start()` 时生效。

```c
/* 关闭机型信息监听（如当前业务不需要机型信息） */
sample_aircraft_info_set_enabled(false);

/* 查询监听启停状态 */
if (sample_aircraft_info_enabled()) {
    printf("[aircraft_info] 机型信息监听已开启\n");
}

/* 查询是否已收到过推送 */
if (sample_aircraft_info_got_push()) {
    printf("[aircraft_info] 已获取机型信息\n");
}
```

### 停止监听

不再需要机型信息时，调用 `sample_aircraft_info_stop()` 注销监听器。

```c
sample_aircraft_info_stop();
sample_session_close(s);
```
