## 概述

自定义控件（Widget）用于在飞机 App 界面上展示负载的交互控件和浮窗信息，例如按钮、开关、滑动条、列表、整数输入框等。

飞机可读取控件配置、设置或读取控件值；负载注册回调响应这些命令，并主动上报控件状态与浮窗消息。控件配置文件由负载侧 HTTP 服务传输。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-custom-widget.html" target="_blank" rel="noopener noreferrer">协议参考-自定义控件</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**控件命令响应端 (impl)**

负载侧用于接收并响应飞机下发的 3 个控件命令的对象。负载为每个命令注册一个处理回调，飞机下发对应命令时由 SDK 回调到负载。

**控件状态推送端 (publisher)**

负载侧用于主动向飞机上报控件状态与浮窗消息的对象。负载周期通过该对象推送控件状态列表与浮窗文本。

**控件类型**

自定义控件支持的类型：Button（按钮）、Switch（开关）、Scale（滑动条）、List（列表）、IntInputBox（整数输入框）。控件的布局与初值由控件配置文件（`widget_config.json`）定义。

### 控件配置文件

控件布局定义在配置文件中。飞机先通过「获取控件文件列表」接口取得列表（含 `md5`），再经负载侧 HTTP 服务下载文件本体；负载按 APP 语言与屏幕类型返回对应的配置文件列表。

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 创建响应端与推送端

在已建立的 MQTT 会话 `s` 上创建控件命令响应端与状态推送端，后续命令回调通过响应端注册，状态与浮窗推送通过推送端发出。

```c
WidgetImpl_t *wimpl = WidgetImpl_Create(s, device_sn);
Widget_Publisher_t *wpub = Widget_CreatePublisher(s);
```

### 获取控件文件列表

注册「获取控件文件列表」回调。飞机下发该命令时，负载在回调中按请求的语言与屏幕类型返回控件配置文件列表。对应的 MQTT 协议见 <a href="../api-reference/api-custom-widget.html#获取控件文件列表" target="_blank" rel="noopener noreferrer">获取控件文件列表</a>。

```c
static T_ThingModelReturnCode on_get_file_list(WidgetImpl_t *impl, void *user,
        const T_WidgetGetFileListRequest *req, T_WidgetGetFileListReply *reply)
{
    E_AppLanguage lang = req ? req->language : APP_LANGUAGE_ENGLISH;

    T_WidgetFileInfo *arr = ThingModelMem_Calloc(1, sizeof(*arr));
    arr[0].file_index = 0;
    arr[0].file_name  = ThingModelMem_Strdup("widget_config.json");
    arr[0].file_size  = 2048;
    arr[0].md5        = ThingModelMem_Strdup("9e107d9d372bb6826bd81d3542a419d6");

    reply->result          = 0;
    reply->result_message  = ThingModelMem_Strdup("success");
    reply->file_list       = arr;
    reply->file_list_count = 1;
    return THING_MODEL_RC_OK;
}

WidgetImpl_OnGetFileList(wimpl, on_get_file_list, NULL);
```

:::tip 说明：
`T_WidgetGetFileListReply` 的 `result_message` 及文件项的 `file_name`、`md5` 均为 `char *`，SDK 回包后会释放，须用 `ThingModelMem_Strdup` 等方式堆分配；`file_list` 数组用 `ThingModelMem_Calloc` 分配，`file_list_count` 填实际文件数。
:::

请求结构 `T_WidgetGetFileListRequest` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| language | E_AppLanguage | APP 系统语言。<ul><li>APP_LANGUAGE_ENGLISH（0）：英语</li><li>APP_LANGUAGE_CHINESE_SIMPLIFIED（1）：中文简体</li><li>APP_LANGUAGE_JAPANESE（2）：日语</li><li>APP_LANGUAGE_FRENCH（3）：法语</li></ul> |
| screen_type | E_ScreenType | APP 屏幕类型。<ul><li>SCREEN_TYPE_LARGE（0）：大屏</li><li>SCREEN_TYPE_SMALL（1）：小屏</li></ul> |

应答结构 `T_WidgetGetFileListReply` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| result | int32_t | 处理结果，0 表示成功 |
| result_message | char * | 结果描述信息 |
| file_list | T_WidgetFileInfo * | 控件配置文件列表 |
| file_list_count | size_t | 文件列表元素个数 |

文件项结构 `T_WidgetFileInfo` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| file_index | int32_t | 文件索引 |
| file_name | char * | 文件名，如 `widget_config.json` |
| file_size | int32_t | 文件大小，单位字节 |
| md5 | char * | 文件 MD5，用于校验与判断是否需要更新 |

### 设置控件值

注册「设置控件值」回调。飞机下发该命令时，负载在回调中更新对应控件的值并返回结果。对应的 MQTT 协议见 <a href="../api-reference/api-custom-widget.html#设置控件值" target="_blank" rel="noopener noreferrer">设置控件值</a>。

```c
static T_ThingModelReturnCode on_set_value(WidgetImpl_t *impl, void *user,
        const T_WidgetSetValueRequest *req, T_ThingModelCommonReply *reply)
{
    apply_widget_value(req->widget_index, req->widget_type, req->widget_value);
    reply->result = 0;
    snprintf(reply->result_message, sizeof(reply->result_message), "success");
    return THING_MODEL_RC_OK;
}

WidgetImpl_OnSetValue(wimpl, on_set_value, NULL);
```

:::tip 说明：
`T_ThingModelCommonReply` 的 `result_message` 为定长字符数组，应使用 `snprintf` 填写，不应使用 `strdup`。
:::

请求结构 `T_WidgetSetValueRequest` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| widget_index | int32_t | 控件索引 |
| widget_type | int32_t | 控件类型。<ul><li>1：Button</li><li>2：Switch</li><li>3：Scale</li><li>4：List</li><li>5：IntInputBox</li></ul> |
| widget_value | int32_t | 控件值 |

### 读取控件值

注册「读取控件值」回调。飞机下发该命令时，负载在回调中回显控件索引并返回当前值。对应的 MQTT 协议见 <a href="../api-reference/api-custom-widget.html#读取控件值" target="_blank" rel="noopener noreferrer">读取控件值</a>。

```c
static T_ThingModelReturnCode on_get_value(WidgetImpl_t *impl, void *user,
        const T_WidgetGetValueRequest *req, T_WidgetGetValueReply *reply)
{
    reply->result         = 0;
    reply->result_message = ThingModelMem_Strdup("success");
    reply->widget_index   = req->widget_index;
    reply->widget_value   = query_widget_value(req->widget_index);
    return THING_MODEL_RC_OK;
}

WidgetImpl_OnGetValue(wimpl, on_get_value, NULL);
```

:::tip 说明：
`T_WidgetGetValueReply` 的 `result_message` 为 `char *`，SDK 回包后会释放，须用 `ThingModelMem_Strdup` 等方式堆分配。
:::

应答结构 `T_WidgetGetValueReply` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| result | int32_t | 处理结果，0 表示成功 |
| result_message | char * | 结果描述信息 |
| widget_index | int32_t | 控件索引（回显请求中的索引） |
| widget_value | int32_t | 控件当前值 |

### 推送控件状态

通过推送端主动向飞机上报全部控件的当前状态。构造控件状态列表后调用推送接口。对应的 MQTT 协议见 <a href="../api-reference/api-custom-widget.html#控件状态推送" target="_blank" rel="noopener noreferrer">控件状态推送</a>。

```c
T_WidgetStateItem items[1] = {
    { .widget_index = 2, .widget_type = (char *)"switch", .widget_value = 1 },
};
T_WidgetStatePush push = { .widget_list = items, .widget_list_count = 1 };
Widget_PublishState(wpub, &push);
```

推送结构 `T_WidgetStatePush` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| widget_list | T_WidgetStateItem * | 控件状态列表 |
| widget_list_count | size_t | 控件状态列表元素个数 |

状态项结构 `T_WidgetStateItem` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| widget_index | int32_t | 控件索引 |
| widget_type | char * | 控件类型。<ul><li>button</li><li>list</li><li>switch</li><li>scale</li><li>int_input_box</li></ul> |
| widget_value | int32_t | 控件当前值 |

### 推送浮窗消息

通过推送端主动向飞机上报浮窗显示的文本消息。对应的 MQTT 协议见 <a href="../api-reference/api-custom-widget.html#浮窗消息推送" target="_blank" rel="noopener noreferrer">浮窗消息推送</a>。

```c
T_WidgetFloatWindowPush fw = { .message = (char *)"payload status: OK" };
Widget_PublishFloatWindowMsg(wpub, &fw);
```

推送结构 `T_WidgetFloatWindowPush` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| message | char * | 浮窗显示的消息文本 |

### 销毁响应端与推送端

不再使用自定义控件功能时，销毁响应端与推送端以释放资源。

```c
WidgetImpl_Destroy(wimpl);
Widget_DestroyPublisher(wpub);
```
