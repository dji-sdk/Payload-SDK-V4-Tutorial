## 概述

:::warning 注意：
对于 Matrice 5TD 机型，同一时刻仅允许一个负载口使能并使用 EFTS 功能。若多个负载口同时使用 EFTS，飞行平台可能对 PWM 信号产生误检测，导致 EFTS 功能无法正常工作。请确保整机上仅有一个负载口启用 EFTS。
:::

紧急降落通过应急飞行终止系统（EFTS，Emergency Flight Termination System）实现。EFTS 是飞行终止系统（FTS）的硬件实现方式，通过负载硬件输出的 PWM 信号触发飞行平台停桨，不依赖软件指令链路。

负载可在地面端使能飞控侧 FTS PWM 触发口，也可查询 FTS PWM 触发状态。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-eu-c6.html" target="_blank" rel="noopener noreferrer">协议参考-紧急降落</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**飞行终止系统 (FTS, Flight Termination System)**

在飞行出现安全隐患时主动强制停止飞行、并独立于飞行器自身控制系统的一套设备和软件。

**应急飞行终止系统 (EFTS, Emergency Flight Termination System)**

EFTS 是 FTS 的硬件实现方式。负载设备通过接口向飞行平台主动输出符合规格的 PWM 信号，飞行平台检测到信号满足条件后立即执行电机停桨操作，不依赖软件指令链路。

### 机型支持与硬件信号要求

负载设备需根据下表中对应机型的参数，向指定接口的 FTS 引脚输出合规的 PWM 信号：

| 机型 | 支持接口 | PWM 频率 | 占空比 | 电压 |
|------|---------|---------|--------|------|
| Matrice 5TD | E-Port V3 接口 FTS 引脚 | 400 Hz | 50% | 3.3 V |

:::warning 注意：
- Matrice 5TD 机型约束：
  - EFTS 功能不能与基于 PPS 信号的功能（如时间同步的 PPS 信号源）同时使用。若已启用基于 PPS 信号的功能，需先关闭该功能并重新插拔负载后，方可使用 EFTS 功能。
  - 同一时刻只能有一个负载口向飞机发送 PWM 波触发 EFTS 功能，否则紧急降落功能可能无法正常实现。
:::

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 创建客户端

在已建立的 MQTT 会话 `s` 上创建 EFTS 客户端，后续接口均通过该客户端调用。

```c
Efts_Client_t *efts = Efts_CreateClient(s);
```

### 使能 FTS PWM 触发口

在地面端使能飞控侧的 FTS PWM 触发口。本接口仅使能触发口，不发出 PWM 信号，也不执行停桨动作；实际停桨由外部 PWM 硬件向该端口输出符合规格的 PWM 信号触发。对应的 MQTT 协议见 <a href="../api-reference/api-eu-c6.html#使能-pwm-触发口" target="_blank" rel="noopener noreferrer">使能 PWM 触发口</a>。

```c
T_ThingModelCommonReply resp = {0};
T_ThingModelReturnCode rc = Efts_SelectFtsPwmTrigger(efts, NULL, &resp, 5000);
if (rc == THING_MODEL_RC_OK && resp.result == 0) {
    USER_LOG_INFO("select fts pwm trigger success.");
} else {
    USER_LOG_ERROR("select fts pwm trigger failed: rc=%d result=%d msg=%s",
                   rc, resp.result, resp.result_message);
}
```

:::tip 说明：
本接口无入参，调用时 `req` 传 `NULL`（`data` 为空对象 `{}`）。
:::

#### 树莓派输出 PWM 触发信号示例

触发口使能后，还需由外部硬件按规格向 FTS 引脚输出 PWM 信号，飞行平台才会执行停桨。以下以树莓派（Raspberry Pi 4B）为例，介绍如何通过 GPIO 18 输出一路 400 Hz、占空比 50% 的方波，用于模拟负载的 PWM 触发信号。示例采用树莓派 SoC 片上硬件 PWM（`/sys/class/pwm`），而非软件模拟 PWM，以保证信号频率和占空比的稳定性。

:::warning 注意：
树莓派 4B 的 GPIO 18 硬件 PWM 通道默认被板载音频功能占用，首次使用前需修改 `/boot/config.txt` 并重启，完成一次性配置：

1. 将 `dtparam=audio=on` 改为 `dtparam=audio=off`，释放硬件 PWM 通道。
2. 在文件末尾追加一行，将 GPIO 18、19 复用为硬件 PWM 输出：

```
dtoverlay=pwm-2chan,pin=18,func=2,pin2=19,func2=2
```

3. 保存后重启树莓派使配置生效。

配置生效后，`/sys/class/pwm/` 目录下会出现 `pwmchip0` 设备节点，运行样例即可在 GPIO 18 上观察到 400 Hz 方波。
:::

示例代码通过操作 `/sys/class/pwm/pwmchip0` 节点导出、配置并使能 PWM 通道：

```shell
# 导出 PWM 通道 0（对应 GPIO 18）
echo 0 > /sys/class/pwm/pwmchip0/export

# 配置周期与占空比，单位为纳秒
# 400 Hz -> 周期 2500000 ns，占空比 50% -> 高电平时长 1250000 ns
echo 2500000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 1250000 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle

# 使能 PWM 输出
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
```

:::tip 说明：
- 上述 shell 命令仅用于说明配置流程，EFTS 样例中已封装为可直接运行的程序，运行后即在 GPIO 18 上持续输出满足 Matrice 5TD 机型要求的 400 Hz、占空比 50% 方波。
- 停止输出时，可将 `enable` 写为 `0`，并向 `unexport` 写入通道号释放资源。
- 该方波仅用于本地验证 EFTS 硬件触发链路，实际负载设备需根据自身硬件条件，将等效的 PWM 信号接入飞行平台指定的 FTS 引脚。
:::

### 查询 FTS PWM 触发状态

查询当前 FTS PWM 触发状态及累计正确接收到的 PWM 停桨信号次数。如需确认停桨执行效果，可同时订阅飞控 ESC 数据，通过电调转速进行校验。对应的 MQTT 协议见 <a href="../api-reference/api-eu-c6.html#查询-fts-pwm-触发状态" target="_blank" rel="noopener noreferrer">查询 FTS PWM 触发状态</a>。

```c
T_EftsGetFtsTriggerStatusReply r = {0};
T_ThingModelReturnCode rc = Efts_GetFtsTriggerStatus(efts, NULL, &r, 5000);
if (rc == THING_MODEL_RC_OK && r.result == 0) {
    USER_LOG_INFO("fts_status=%d  fts_pwm_cnt=%d", (int)r.fts_status, r.fts_pwm_cnt);
} else {
    USER_LOG_ERROR("get fts trigger status failed: rc=%d result=%d msg=%s",
                   rc, r.result, r.result_message);
}
```

应答结构 `T_EftsGetFtsTriggerStatusReply` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| result | int32_t | 处理结果，0 表示成功 |
| result_message | char * | 结果描述信息 |
| fts_status | E_EftsFtsStatus | FTS PWM 触发状态。<ul><li>EFTS_FTS_STATUS_NOT_TRIGGERED（0）：未触发</li><li>EFTS_FTS_STATUS_TRIGGERED（1）：已触发</li></ul> |
| fts_pwm_cnt | int32_t | 累计正确接收到的 PWM 停桨信号次数 |

### 销毁客户端

不再使用 EFTS 功能时，销毁客户端以释放资源。

```c
Efts_DestroyClient(efts);
```
