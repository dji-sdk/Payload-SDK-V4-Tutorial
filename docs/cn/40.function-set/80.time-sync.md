## 概述

:::warning 注意：
时间同步的 PPS 信号源与基于 PPS 信号的其他功能存在互斥约束。对于 Matrice 5TD 机型，PPS 信号不能与 EFTS 等基于 PWM/PPS 的功能同时使用；若已启用 EFTS，需先关闭并重新插拔负载后，方可切换到 PPS 时间同步。
:::

时间同步（Time Sync）用于让负载与飞行平台保持一致的时间基准。负载可选择时间同步信号源：FTS 信号（默认）或 PPS 信号。当信号源为 PPS 时，飞机端按周期向负载推送 UTC 时间，负载据此校准本地时钟。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-time-sync.html" target="_blank" rel="noopener noreferrer">协议参考-时间同步</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**FTS 信号**

时间同步的默认信号源。该引脚与<a href="eu-c6.html" target="_blank" rel="noopener noreferrer">紧急降落</a>的 FTS 触发引脚为同一物理引脚（引脚复用）：处于 FTS 模式时，该引脚用于紧急降落，不用于时间同步，因此飞机端不推送 UTC 时间。需要时间同步时应将信号模式切换为 PPS。

**PPS 信号 (PPS, Pulse Per Second)**

秒脉冲信号。将时间同步信号源切换为 PPS 后，飞机端按周期向负载推送 UTC 时间，用于将负载本地时钟与飞行平台对齐。

### 信号模式与 UTC 上报关系

时间同步的 UTC 时间上报由信号模式决定：

1. 负载调用 `TimeSync_SetSignalMode()` 将模式设为 PPS。
2. 飞机端开始通过 `time_sync` event 周期推送 UTC 时间，负载在注册的回调中收到。

:::warning 注意：
回调在后台线程触发，回调内不应调用时间同步 API 或销毁客户端，耗时操作应转交其他线程处理。
:::

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 创建客户端

在已建立的 MQTT 会话 `s` 上创建时间同步客户端，后续接口均通过该客户端调用。

```c
TimeSync_Client_t *ts = TimeSync_CreateClient(s);
```

### 接收 UTC 时间

注册回调以接收飞机端推送的 UTC 时间。回调在信号模式为 PPS 时被周期触发，参数 `p` 指向解码后的 UTC 时间结构体。应先注册回调，再切换到 PPS 模式，避免漏收早期上报。对应的 MQTT 协议见 <a href="../api-reference/api-time-sync.html#接收-utc-时间" target="_blank" rel="noopener noreferrer">接收 UTC 时间</a>。

```c
static void on_time_sync(void *user, const T_TimeSyncTimeSyncPush *p)
{
    if (!p) return;
    USER_LOG_INFO("UTC %04d-%02d-%02d %02d:%02d:%02d.%09d",
                  p->year, p->month, p->day,
                  p->hour, p->minute, p->second, p->nano_second);
}

T_ThingModelReturnCode rc = TimeSync_OnSync(ts, on_time_sync, NULL);
if (rc != THING_MODEL_RC_OK) {
    USER_LOG_ERROR("subscribe time_sync failed: rc=%d", rc);
}
```

推送结构 `T_TimeSyncTimeSyncPush` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| year | int32_t | 年 |
| month | int32_t | 月，取值 1~12 |
| day | int32_t | 日，取值 1~31 |
| hour | int32_t | 小时，取值 0~23 |
| minute | int32_t | 分钟，取值 0~59 |
| second | int32_t | 秒，取值 0~59 |
| nano_second | int32_t | 纳秒，取值 0~999999999 |

### 设置时间同步信号模式

设置时间同步信号源。传入 `TIME_SYNC_SIGNAL_MODE_PPS` 切换到 PPS 后，飞机端开始推送 UTC 时间；传入 `TIME_SYNC_SIGNAL_MODE_FTS` 改回默认后停止推送。对应的 MQTT 协议见 <a href="../api-reference/api-time-sync.html#设置时间同步信号模式" target="_blank" rel="noopener noreferrer">设置时间同步信号模式</a>。

```c
T_TimeSyncSetSignalModeRequest req;
TimeSync_InitTimeSyncSetSignalModeRequest(&req);
req.mode = TIME_SYNC_SIGNAL_MODE_PPS;

T_ThingModelCommonReply resp = {0};
T_ThingModelReturnCode rc = TimeSync_SetSignalMode(ts, &req, &resp, 5000);
if (rc == THING_MODEL_RC_OK && resp.result == 0) {
    USER_LOG_INFO("set signal mode PPS success.");
} else {
    USER_LOG_ERROR("set signal mode failed: rc=%d result=%d msg=%s",
                   rc, resp.result, resp.result_message);
}
```

信号模式枚举 `E_TimeSyncSignalMode` 取值：

| 枚举常量 | 数值 | 含义 |
|------|------|------|
| TIME_SYNC_SIGNAL_MODE_FTS | 0 | FTS 信号（默认） |
| TIME_SYNC_SIGNAL_MODE_PPS | 1 | PPS 信号 |

:::tip 说明：
调用前应先用 `TimeSync_InitTimeSyncSetSignalModeRequest()` 初始化请求结构体，再设置 `mode` 字段。
:::

### 销毁客户端

不再使用时间同步功能时，销毁客户端以释放资源。

```c
TimeSync_DestroyClient(ts);
```
