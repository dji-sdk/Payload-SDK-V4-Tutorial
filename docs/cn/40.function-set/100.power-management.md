## 概述

电源管理（Power）用于协调负载与飞机的供电状态，提供关机通知接口。

飞机下电前会向负载发送关机通知，负载在响应中返回是否已准备好下电。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-power-management.html" target="_blank" rel="noopener noreferrer">协议参考-电源管理</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**关机通知**

飞机在下电前向负载下发的通知。负载收到后应完成数据保存、外设断电等收尾操作，并在响应中通过 `preparation_flag` 告知飞机是否已准备好下电。

**关机通知响应端 (impl)**

负载侧用于接收并响应飞机下发关机通知的对象。负载注册处理回调，飞机下发关机通知时由 SDK 回调到负载。

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 创建响应端

在已建立的 MQTT 会话 `s` 上创建关机通知响应端，用于注册关机通知回调。

```c
PowerImpl_t *impl = PowerImpl_Create(s, device_sn);
```

### 响应关机通知

注册「关机通知」回调。飞机下发关机通知时，负载在回调中完成下电前的收尾操作，并通过 `preparation_flag` 返回是否已准备好下电。对应的 MQTT 协议见 <a href="../api-reference/api-power-management.html#关机通知" target="_blank" rel="noopener noreferrer">关机通知</a>。

```c
static T_ThingModelReturnCode on_power_off(PowerImpl_t *impl, void *user,
                                           const T_Placeholder *req,
                                           T_PowerOffNotificationReply *reply)
{
    reply->result           = 0;
    reply->result_message   = strdup("success");
    reply->preparation_flag = true;   /* 已准备好下电 */
    return THING_MODEL_RC_OK;
}

PowerImpl_OnPowerOffNotification(impl, on_power_off, NULL);
```

:::tip 说明：
`T_PowerOffNotificationReply` 的 `result_message` 为 `char *`，SDK 回包后会释放，须用 `strdup` 等方式堆分配，不能使用字符串字面量或栈地址。回调在后台线程触发，回调内不应调用电源管理 API 或销毁响应端，耗时操作应转交其他线程处理。
:::

应答结构 `T_PowerOffNotificationReply` 的字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| result | int32_t | 处理结果，0 表示成功 |
| result_message | char * | 结果描述信息 |
| preparation_flag | bool | 是否已准备好下电。<ul><li>false：未准备好</li><li>true：已准备好</li></ul> |

### 销毁响应端

不再使用电源管理功能时，销毁响应端以释放资源。

```c
PowerImpl_Destroy(impl);
```
