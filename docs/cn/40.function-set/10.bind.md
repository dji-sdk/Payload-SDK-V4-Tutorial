## 概述

:::warning 注意：
应用绑定是业务功能的前置条件。设备未绑定时，飞机端会拒绝业务请求；负载上线后应先确认绑定状态，再启动控件、喊话器等业务功能。
:::

本章介绍负载侧如何**监听与查询绑定状态**。应用绑定（Bind）用于确认负载设备与飞行平台的授权关系；设备接入 MQTT 后，若尚未绑定，飞机端会通过事件通道推送 `bind_required`，负载监听该事件后可暂停后续业务请求，并引导飞手在 DJI Assistant 2 完成绑定。绑定概念与流程详见 <a href="../payload-quick-start/app-bind.html" target="_blank" rel="noopener noreferrer">应用绑定</a>。

负载侧无需主动发起绑定请求，只需订阅事件通道并处理绑定状态变化。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-bind.html" target="_blank" rel="noopener noreferrer">协议参考-绑定状态通知</a>。  
- 设备需先完成接入与鉴权，方可接入 broker 并进行绑定，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**绑定（Bind）**

负载设备与飞行平台的身份授权关系。绑定后，飞机端才允许负载设备通过 MQTT 服务器进行业务交互。未绑定时飞机端通常拒绝所有 service 请求。

**bind_required 事件**

飞机端主动推送的设备级事件。当设备连接 MQTT 服务器且飞机端检测到未绑定时，飞机端在 `thing/product/{client_id}/events` 通道推送该事件，携带当前绑定状态（`bind_state`）及说明信息，提示负载通过 DJI Assistant 2 完成绑定流程。

### 绑定状态（BindState）

描述设备当前绑定进度的枚举，共 9 个值：

| 枚举常量 | 值 | 说明 |
|---|---|---|
| BIND_STATE_IDLE | 0 | 空闲，尚未开始绑定检查 |
| BIND_STATE_CHECKING | 1 | 正在查询绑定状态 |
| BIND_STATE_BOUND | 2 | 已绑定 |
| BIND_STATE_BINDING | 3 | 绑定中，正在等待 DJI Assistant 2 完成绑定 |
| BIND_STATE_BIND_SUCCESS | 4 | 绑定成功 |
| BIND_STATE_BIND_FAILED | 5 | 绑定失败 |
| BIND_STATE_UNBINDING | 6 | 正在等待 DJI Assistant 2 完成解绑 |
| BIND_STATE_UNBIND_SUCCESS | 7 | 解绑成功 |
| BIND_STATE_UNBIND_FAILED | 8 | 解绑失败 |

### 监听机制

绑定模块通过 `ThingModelClientSession_AddListener()` 在已有 MQTT 会话上注册消息监听，不创建额外的 MQTT 连接。监听器收到消息后先校验消息类型，仅在消息类型为 `bind_required` 时进行 JSON 解码，以减少对消息分发流程的影响。

:::warning 注意：
监听器回调运行在后台消息分发线程上。回调内不得注销监听器或销毁会话，否则会因内部锁竞争产生死锁；也不应调用同步接口，否则会阻塞分发线程直至超时，导致本次同步调用的响应无法分发。耗时逻辑应转交其他线程处理。
:::

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 启动监听

在建立 MQTT 会话后立即调用 `bind_monitor_start()`，注册监听器并订阅事件通道。该接口可重复调用，重复调用不会重复注册监听器。对应的 MQTT 协议见 <a href="../api-reference/api-bind.html#bind-required-事件" target="_blank" rel="noopener noreferrer">bind_required 事件</a>。

```c
ThingModelClientSession_t *s = sample_session_open(&cfg);
if (!s) { /* 处理连接失败 */ return -1; }

/* 会话建立后立即注册绑定监听 */
bind_monitor_start(s);
```

:::tip 说明：
`bind_monitor_start()` 内部调用 `ThingModelClientSession_Subscribe()` 订阅 `thing/product/{sn}/events`。`auto_reconnect` 开启时，断线重连后会自动重新订阅。
:::

### 查询绑定状态

启动监听后，可在业务代码中随时调用状态查询接口，决定是否继续执行后续业务请求。

```c
/* 保守放行策略：从未收到过 bind 推送时视为已绑定（飞机端只在异常时推，没推=无需拦截） */
if (!bind_monitor_is_bound()) {
    printf("[main] 设备未绑定，当前 bind_state=%d；请通过 DJI Assistant 2 完成绑定后重试\n",
           bind_monitor_state());
    /* 等待绑定完成后再启动业务功能 */
}

/* 严格判定：确认收到 bind 推送后再判断是否放行 */
if (bind_monitor_got_push() && !bind_monitor_is_bound()) {
    printf("[main] 收到绑定通知，设备未绑定（state=%d）\n", bind_monitor_state());
}
```

以下为 `bind_required` 事件推送后的典型处理逻辑：

```c
/* 在会话监听器回调中（参考 sample_bind.c 内部实现）*/
static void on_session_msg(void *user, const char *topic,
                           const char *payload, size_t len)
{
    /* 仅处理事件通道的消息 */
    if (!strstr(topic, "event"))                          return;
    /* 仅在收到目标消息时解码 */
    if (!payload_contains(payload, len, "bind_required")) return;

    T_BindRequired b;
    Bind_InitBindRequired(&b);
    if (BindJson_DecodeBindRequired(payload, &b) == THING_MODEL_RC_OK) {
        printf("[bind] 设备绑定状态: %d (%s) — %s\n",
               (int)b.bind_state,
               b.bind_state_desc ? b.bind_state_desc : "-",
               b.message         ? b.message         : "-");
        if (b.bind_state != BIND_STATE_BOUND) {
            printf("[bind] 设备未绑定/绑定未完成，请通过 DJI Assistant 2 完成绑定后重试\n");
        }
    }
    Bind_FreeBindRequired(&b);
}
```

事件数据结构 `T_BindRequired` 的字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| bind_state | E_BindState | 绑定状态枚举，见 [绑定状态（BindState）](#绑定状态-bindstate) |
| bind_state_desc | char * | 状态描述字符串，如 "BINDING" |
| message | char * | 提示信息，如 "Binding in progress. Waiting for DA2 to complete binding." |
| timestamp_ms | int64_t | 飞机端发送时间戳，单位毫秒 |

### 停止监听

不再需要监听绑定状态时，调用 `bind_monitor_stop()` 注销监听器并释放资源。

```c
bind_monitor_stop();
sample_session_close(s);
```
