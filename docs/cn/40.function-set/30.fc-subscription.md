## 概述

数据订阅（Data Subscription）用于按需获取飞机遥测数据，涵盖姿态、速度、位置、GPS、RTK、遥控、飞行状态、云台、避障、电池等主题。

负载可订阅主题、取消订阅或查询最新值；订阅成功后，飞控通过 osd 通道按设定频率推送数据，不同主题会以不同消息上报。

:::tip 说明：
- PSDK 中的 C 接口是对底层 MQTT 协议的封装，开发者通过调用 C 接口即可完成协议交互，无需手动构造 MQTT 报文。底层 MQTT 协议的 payload 结构与字段定义详见 <a href="../api-reference/api-fc-subscription.html" target="_blank" rel="noopener noreferrer">协议参考-数据订阅</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，详见 <a href="access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 基础概念

### 名词解释

**主题 (topic)**

飞控可订阅的一类遥测数据的标识，如 `quaternion`（四元数）、`velocity`（速度）、`battery_single_info_index1`（电池 1 详情）。每个主题对应一组固定字段，全部主题详见 [订阅主题列表](#订阅主题列表)。

**订阅频率 (frequency)**

飞控推送某主题数据的频率，单位 Hz。可选 1 / 5 / 10 / 50 Hz。对同一主题重复调用订阅接口可更新频率，新频率覆盖旧订阅。

**osd 推送**

飞控向负载推送订阅数据的通道。飞控按各主题的订阅频率推送数据，不同主题的数据会通过不同消息分别推送，负载通过订阅 osd 通道接收这些推送消息。

### 订阅频率与推送关系

数据订阅的推送由订阅状态与频率共同决定：

1. 负载调用 `DataSubscription_SubscribeTopic()` 订阅主题并设置频率。
2. 飞控按该频率推送该主题数据，负载从 osd 通道接收。
3. 负载调用 `DataSubscription_UnsubscribeTopic()` 取消订阅，飞控停止推送该主题。

:::warning 注意：
批量订阅多个主题时，应分批发送并在请求间留出间隔，避免短时间内大量请求积压导致订阅失败或超时。接收数据的处理应在后台线程进行，处理逻辑内不应调用数据订阅 API，也不应销毁客户端；耗时逻辑应转交其他线程处理。
:::

### 订阅主题列表

数据订阅支持姿态、位置、速度、GPS、RTK、遥控、飞行状态、云台、避障、电池等多类遥测主题。各主题的 `topic` 取值、建议订阅频率与数据字段结构，见协议文档 <a href="../api-reference/api-fc-subscription.html#订阅主题一览" target="_blank" rel="noopener noreferrer">订阅主题一览</a> 与 <a href="../api-reference/api-fc-subscription.html#飞控数据推送" target="_blank" rel="noopener noreferrer">飞控数据推送</a>。

:::tip 说明：
不同机型支持的主题可能存在差异，订阅接口返回成功但某主题长期无推送数据时，通常表示当前机型不支持该主题。表中频率为建议值，实际支持的频率以具体主题为准。
:::

## 功能介绍

:::warning 注意：
以下代码为参考示例，用于说明各功能的调用流程与实现方式。开发者可结合负载设备的硬件特性和应用场景进行适配。
:::

### 创建客户端

在已建立的 MQTT 会话 `s` 上创建数据订阅客户端，后续接口均通过该客户端调用。

```c
DataSubscription_Client_t *ds = DataSubscription_CreateClient(s);
```

### 接收推送数据

负载订阅 osd 通道接收飞控推送的订阅数据。飞控按订阅频率推送数据，不同主题的数据会通过不同消息分别推送，负载在消息处理中解析对应主题的字段。对应的 MQTT 协议见 <a href="../api-reference/api-fc-subscription.html#飞控数据推送" target="_blank" rel="noopener noreferrer">飞控数据推送</a>。

```c
static void on_publish_data(void *user, const T_DataSubscriptionPublishDataPush *p)
{
    if (!p) return;
    /* p 中仅已订阅主题字段被填充，未订阅主题保持零值 */
    USER_LOG_INFO("quaternion: q0=%.4f q1=%.4f q2=%.4f q3=%.4f",
                  p->quaternion.q0, p->quaternion.q1,
                  p->quaternion.q2, p->quaternion.q3);
    USER_LOG_INFO("velocity: x=%.3f y=%.3f z=%.3f health=%d",
                  p->velocity.x, p->velocity.y, p->velocity.z, p->velocity.health);
}

T_ThingModelReturnCode rc = DataSubscription_OnPublishData(ds, on_publish_data, NULL);
if (rc != THING_MODEL_RC_OK) {
    USER_LOG_ERROR("register publish data callback failed: rc=%d", rc);
}
```

:::warning 注意：
接收数据的处理在后台线程进行，处理逻辑内不应调用数据订阅 API，也不应销毁客户端；耗时逻辑应转交其他线程处理。
:::

### 订阅主题

订阅指定主题并设置飞控推送频率。订阅成功后飞控开始按 `frequency` 频率推送该主题数据。对同一主题重复调用可更新频率。对应的 MQTT 协议见 <a href="../api-reference/api-fc-subscription.html#订阅主题" target="_blank" rel="noopener noreferrer">订阅主题</a>。

```c
T_DataSubscriptionSubscribeTopicRequest req;
DataSubscription_InitDataSubscriptionSubscribeTopicRequest(&req);
req.topic     = "quaternion";
req.frequency = DATA_SUBSCRIPTION_FREQUENCY_10HZ;

T_ThingModelCommonReply resp = {0};
T_ThingModelReturnCode rc = DataSubscription_SubscribeTopic(ds, &req, &resp, 5000);
if (rc == THING_MODEL_RC_OK && resp.result == 0) {
    USER_LOG_INFO("subscribe quaternion 10Hz success.");
} else {
    USER_LOG_ERROR("subscribe topic failed: rc=%d result=%d msg=%s",
                   rc, resp.result, resp.result_message);
}
```

订阅频率枚举 `E_DataSubscriptionFrequency` 取值：

| 枚举常量 | 数值 | 含义 |
|------|------|------|
| DATA_SUBSCRIPTION_FREQUENCY_1HZ | 1 | 1 Hz |
| DATA_SUBSCRIPTION_FREQUENCY_5HZ | 5 | 5 Hz |
| DATA_SUBSCRIPTION_FREQUENCY_10HZ | 10 | 10 Hz |
| DATA_SUBSCRIPTION_FREQUENCY_50HZ | 50 | 50 Hz |

:::tip 说明：
调用前应先用 `DataSubscription_InitDataSubscriptionSubscribeTopicRequest()` 初始化请求结构体，再设置 `topic` 与 `frequency` 字段。批量订阅多个主题时，应分批发送并在请求间加入间隔，避免短时间内大量请求积压导致订阅失败或超时。
:::

### 取消订阅

取消指定主题的订阅，飞控停止推送该主题数据。对应的 MQTT 协议见 <a href="../api-reference/api-fc-subscription.html#取消订阅" target="_blank" rel="noopener noreferrer">取消订阅</a>。

```c
T_DataSubscriptionUnsubscribeTopicRequest req;
DataSubscription_InitDataSubscriptionUnsubscribeTopicRequest(&req);
req.topic = "quaternion";

T_ThingModelCommonReply resp = {0};
T_ThingModelReturnCode rc = DataSubscription_UnsubscribeTopic(ds, &req, &resp, 5000);
if (rc == THING_MODEL_RC_OK && resp.result == 0) {
    USER_LOG_INFO("unsubscribe quaternion success.");
} else {
    USER_LOG_ERROR("unsubscribe topic failed: rc=%d result=%d msg=%s",
                   rc, resp.result, resp.result_message);
}
```

### 查询最新值

一次性查询指定主题的最新数据。查询前需已订阅目标主题。对应的 MQTT 协议见 <a href="../api-reference/api-fc-subscription.html#查询最新值" target="_blank" rel="noopener noreferrer">查询最新值</a>。

```c
T_DataSubscriptionGetLatestValueRequest req;
DataSubscription_InitDataSubscriptionGetLatestValueRequest(&req);
req.topic = "quaternion";

T_ThingModelCommonReply resp = {0};
T_ThingModelReturnCode rc = DataSubscription_GetLatestValue(ds, &req, &resp, 5000);
if (rc == THING_MODEL_RC_OK && resp.result == 0) {
    USER_LOG_INFO("get latest value of quaternion request accepted.");
} else {
    USER_LOG_ERROR("get latest value failed: rc=%d result=%d msg=%s",
                   rc, resp.result, resp.result_message);
}
```

:::tip 说明：
查询结果由 `DataSubscription_GetLatestValue()` 返回，负载从 `resp` 中读取对应主题的数据。
:::

### 销毁客户端

不再使用数据订阅功能时，销毁客户端以释放资源。销毁前应先取消已订阅的主题。

```c
DataSubscription_DestroyClient(ds);
```
