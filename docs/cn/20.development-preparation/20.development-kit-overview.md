本章节介绍 Payload SDK 支持的负载开发套件及硬件平台，帮助开发者了解不同开发套件的接口形态、硬件规格、适配机型及购买方式。开发者可根据目标飞行平台、负载形态、通信接口和供电需求选择合适的开发套件，用于负载方案设计、硬件接入和开发调试。

:::tip 说明：
当前 Payload SDK 仅支持 **Matrice 5TD** 机型通过 **E-Port V3 接口** 接入负载设备，开发调试可使用 **E-Port V3 开发板 + E-Port V3 同轴线**。后续如支持新的机型、接口或开发套件，将在本文档中同步更新。
:::

## 购买开发套件

#### E-Port V3 开发者套件
E-Port V3 开发者套件用于将 Matrice 5TD 飞行器的 E-Port V3 转换成多种标准硬件接口，并提供板载 MCU，方便开发者进行硬件设备连接和 SDK 开发调试，实现到手开箱即用。该套件同时兼容 E-Port V2 接口，可通过开发板上的切换开关选择使用 E-Port V2 或 E-Port V3 接口模式。

E-Port V3 开发板内置 MCU，MCU 型号为 GD32F527ZMT7，板载外扩 SDRAM 8MB，MCU 器件规格和技术文档可从 <font color=#1fA3f6><a href="https://www.gigadevice.com.cn/product/mcu/mcus-product-selector/gd32f527zmt7" target="_blank">兆易创新官网</a></font> 获取。

#### E-Port V3 同轴线

用于将 Matrice 5TD 飞行平台上的 E-Port V3 接口转换成同轴线接口，开发者可根据同轴线引脚定义设计负载硬件接口。
