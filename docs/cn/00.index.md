## Payload SDK V4.0.0 发布记录

### 发布日期

2026-11-05

### 版本说明

Payload SDK V4.0.0 为 V4 系列首个正式版本，采用基于 MQTT 协议的开放实现并以源码形式提供，负载设备通过标准 MQTT 通道完成上线鉴权、控制交互、数据上报、数据传输和升级流程。

### 功能支持列表

本版本已支持以下功能：

- 绑定状态通知：实时获取负载在平台侧的绑定与解绑状态。
- 机型信息：查询飞行器机型、固件版本及负载挂载位置等信息。
- 数据订阅：按需订阅飞行器姿态、位置、速度、电量等飞行状态数据。
- 本地升级：由飞机发起，固件通过 HTTP 传输、升级进度经 MQTT 上报。
- 自定义控件：在 App 侧动态呈现负载自定义的交互控件。
- 喊话器控件：对喊话器类负载进行播报内容与音量等控制。
- 紧急降落：在异常场景下通过硬件 PWM 信号触发飞行平台停桨。
- 时间同步：将负载本地时间与飞行器系统时间进行同步。
- 数据传输：在负载与平台之间进行双向的自定义数据传输。
- 电源管理：协调负载与飞机的供电状态，响应飞机下发的关机通知。
- SDK 互联互通：实现负载与其他 SDK 设备之间的数据交互。
