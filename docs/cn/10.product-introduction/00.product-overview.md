

## 概述

Payload SDK 是一套用于扩展无人机负载能力的软件开发接口，支持开发者将自研或第三方负载接入大疆无人机平台，实现远程控制、数据交互及系统协同。SDK 以开放的 MQTT 协议为通信基础，全部样例代码均以源码形式提供。为方便使用 Payload SDK 开发安全可靠的负载设备，请持续关注版本发布信息，及时升级到<a href="../" target="_blank" rel="noopener noreferrer">最新开发包</a>。

## 术语约定

| 术语 | 含义 |
|---|---|
| MQTT 通信协议 | 无人机负载与平台之间基于 MQTT 的应用层通信协议，规定服务、属性、事件与状态四类交互 |
| MQTT Broker | 承载通信协议的 MQTT 服务端，负责设备接入、消息路由与远程管理，下文简称 Broker |
| 负载设备 | 基于本 SDK 开发并可挂载于无人机的功能设备，如喊话器、探照灯、检测仪等 |
| 机载计算平台 | 搭载于无人机的计算单元，可作为负载业务与 SDK 的运行载体 |
| 平台侧应用 | 平台的云端服务或移动端 App，用于对负载设备下发指令与订阅数据 |

## 系统角色与使用方式

在实际应用中，无人机系统通常由飞行平台、负载设备、机载计算平台及平台侧应用协同组成。本 SDK 作为负载能力接入与扩展的核心接口，负责负载与平台之间的通信、控制与数据交互，位于设备侧，是负载与平台之间的协议接入层。

负载设备集成 SDK 后，经 MQTT 连接至 Broker，与平台按通信协议交互：SDK 将平台下发的指令解析为设备可处理的调用，并将设备的执行结果、状态与事件按协议上报。设备端只需专注功能实现，通信、鉴权、重连均由 SDK 处理。

按运行位置的不同，SDK 支持两种部署形态：

- **负载本体运行**：在负载设备的嵌入式控制器（如 MCU / RTOS）上直接集成 SDK，实现负载本体功能；
- **机载计算平台运行**：在机载计算平台（如 Linux）上集成 SDK，与负载设备及平台协同，适合算力需求较高的场景。

## 接入方式

负载接入分为四个阶段：

1. **申请凭据**：获取企业级 App 凭据（App ID / Key / License）与设备身份（Device SN）。
2. **定义能力**：声明负载对外提供的服务、属性、事件与状态。
3. **集成实现**：在负载固件或机载计算平台中集成 SDK，实现所声明的能力。
4. **上线运行**：设备联网并完成鉴权后自动上线，接受平台管理。

设备上线后，通过四类协议交互对外提供能力：

| 交互类型 | 语义 | 方向 |
|---|---|---|
| 服务（Service） | 执行一次性动作并返回结果 | 双向：由负载或飞机发起请求，另一方执行并回执 |
| 属性（Property） | 读取或设置设备配置项 | 双向：负载或飞机发起读写，另一方响应 |
| 事件（Event） | 偶发事件通知 | 双向：负载或飞机按需推送 |
| 状态（State） | 负载的周期或变化状态 | 负载上报飞机 |
| 状态（OSD） | 飞机的周期或变化状态 | 飞机推送负载 |

具体每个接口的发起方与收发方向以对应功能的协议定义为准，详见<a href="../api-reference/api-bind.html">协议参考</a>。

在上述交互之外，SDK 支持远程 OTA 固件升级，以及负载与飞机、负载与云之间的数据透传与订阅。

## 主要优势

**协议与源码完全开放**  
通信过程可审计，接口可核对，无二进制黑盒，便于安全评估与自主定制。

**统一的负载接入能力**  
以统一的接口规范声明并接入负载能力，降低不同负载类型的接入成本，接入过程规范一致，减少协议对接的联调工作。

**支持多种部署形态**  
可运行于负载本体（MCU / RTOS）或机载计算平台（Linux），满足不同算力需求与系统架构选择。

**功能覆盖完善**  
提供信息获取、数据传输、电源管理等基础能力，以及控件交互、远程升级、数据透传与订阅、时间同步等功能，开发者可以根据行业需求，组合出功能完善的负载设备，并便于接入第三方传感器与检测设备采集所需数据。

**广泛的软硬件平台兼容**  
可运行在主流嵌入式 MCU 与操作系统上，覆盖从裸机、RTOS 到 Linux 的多种运行环境。传输、加密、系统适配层均可替换，按跨平台移植步骤即可在不同软硬件平台上运行。

**安全可靠的连接**  
内置 TLS 加密与两阶段身份鉴权；支持断线自动重连与订阅恢复，保障弱网环境下设备持续可控、订阅不丢失。

## 支持的负载能力

| 能力 | 说明 | 典型场景 |
|---|---|---|
| 绑定状态通知 | 监听与查询负载在平台侧的绑定状态 | 负载授权校验、未绑定拦截 |
| 机型信息 | 机型、固件版本、机上设备清单等信息上报 | 负载标识、健康信息、扩展交互 |
| 数据订阅 | 订阅/取消遥测主题、查询最新值 | 实时遥测监看、数据看板 |
| 本地升级 | 平台/飞机侧向负载下发 OTA 升级 | 负载远程维护、批量固件更新 |
| 自定义控件 | 在 App/遥控器上呈现自定义控件，支持控件值读写 | 探照灯、抛投器等负载的自定义操控面板 |
| 喊话器 | 工作/播放模式与音量设置、播放控制、音频分包传输 | 应急喊话、警戒驱离、宣传广播 |
| 紧急降落 | 负载通过硬件 PWM 信号触发飞行平台停桨 | 应急飞行终止、安全保护 |
| 时间同步 | 设备与系统时间同步（含 PPS） | 多传感器时间对齐、精密测绘 |
| 数据传输 | 负载与飞机之间的数据管道 | 自定义协议、私有数据回传 |
| 电源管理 | 负载供电相关的动作与状态 | 负载能耗管理、供电保护 |
| SDK 互联互通 | 负载与其他 SDK 设备之间的数据交互（MOP 通道） | 多 SDK 协同、私有数据链路 |
