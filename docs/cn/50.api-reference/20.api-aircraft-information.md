本章节定义机型信息（Aircraft Information）功能的 MQTT 接口，涵盖 `aircraft_info_push` 事件的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/aircraft-information.html" target="_blank" rel="noopener noreferrer">功能集合-机型信息</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| osd 推送 | 飞机 → 负载 | thing/product/{client_id}/osd |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| aircraft_info_push | osd | 飞机周期推送机型、固件版本、App 信息及设备清单 | sample_aircraft_info_start() 订阅后接收 |

## 公共参数

### 推送参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 消息序列号。 |
| method | string | 是 | 固定为 `aircraft_info_push`。 |
| data | object | 是 | 业务数据主体，见各接口字段说明。 |

## aircraft_info_push 推送

飞机连接 MQTT 服务器后周期推送机型信息，携带机型代号、飞机固件版本、移动端 App 语言与屏幕类型、以及机上所有设备的清单。负载可据此了解当前挂载的飞行平台环境。

对应功能介绍：<a href="../function-set/aircraft-information.html#接收机型信息" target="_blank" rel="noopener noreferrer">接收机型信息</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/osd`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`aircraft_info_push`
- **对应接口**：`sample_aircraft_info_start()` 订阅后被动接收

```json
{
  "seq": 42,
  "method": "aircraft_info_push",
  "data": {
    "aircraft_type": 0,
    "aircraft_version": "01.02.03.04",
    "mobile_app_info": {
      "language": 0,
      "screen_type": 0
    },
    "devices_info": [
      {
        "device_id": "1ZNBJ1234567890",
        "device_name": "EA710",
        "serial_number": "1ZNBJ1234567890",
        "firmware_version": "1.0.0.0",
        "device_type": 1
      }
    ]
  }
}
```

### 字段说明

顶层字段见 [推送参数](#推送参数)，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| aircraft_type | integer | 是 | 机型代号（原始整数，可容纳未来新增机型）。 |
| aircraft_version | string | 是 | 飞机固件版本，如 `01.02.03.04`。 |
| mobile_app_info | object | 是 | 移动端 App 信息。 |
| >>language | integer | 是 | App 当前系统语言类型。<ul><li>0：英语</li><li>1：中文简体</li><li>2：日语</li><li>3：法语</li></ul> |
| >>screen_type | integer | 是 | App 当前屏幕类型。<ul><li>0：大屏</li><li>1：小屏</li></ul> |
| devices_info | array&lt;object&gt; | 是 | 机上设备清单。 |
| >>device_id | string | 是 | 设备 ID，如 `<client_id>`。 |
| >>device_name | string | 是 | 设备名称。 |
| >>serial_number | string | 是 | 序列号。 |
| >>firmware_version | string | 是 | 固件版本。 |
| >>device_type | integer | 是 | 设备类别。<ul><li>1：飞机</li><li>4：负载</li></ul> |
