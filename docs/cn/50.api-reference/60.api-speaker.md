本章节定义喊话器（Speaker）功能的 MQTT 接口，涵盖设置工作模式、设置播放模式、设置音量、开始播放、停止播放、开始音频传输、传输音频数据包、结束音频传输与喊话器状态推送的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/speaker.html" target="_blank" rel="noopener noreferrer">功能集合-喊话器控件</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| service 请求 | 飞机 → 负载 | thing/product/{client_id}/services |
| service 响应 | 负载 → 飞机 | thing/product/{client_id}/services_reply |
| state 推送 | 负载 → 飞机 | thing/product/{client_id}/state |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| speaker_set_work_mode | service | 飞机设置喊话器工作模式 | SpeakerImpl_OnSetWorkMode() |
| speaker_set_play_mode | service | 飞机设置喊话器播放模式 | SpeakerImpl_OnSetPlayMode() |
| speaker_set_volume | service | 飞机设置喊话器音量 | SpeakerImpl_OnSetVolume() |
| speaker_start_play | service | 飞机控制喊话器开始播放 | SpeakerImpl_OnStartPlay() |
| speaker_stop_play | service | 飞机控制喊话器停止播放 | SpeakerImpl_OnStopPlay() |
| speaker_trans_start | service | 飞机开始向负载传输音频文件 | SpeakerImpl_OnTransStart() |
| speaker_trans_data | service | 飞机逐包传输音频二进制数据 | SpeakerImpl_OnTransData() |
| speaker_trans_finish | service | 飞机结束音频传输并校验 | SpeakerImpl_OnTransFinish() |
| speaker_state | state | 负载推送喊话器状态 | Speaker_PublishState() |

## 公共参数

以下参数为喊话器各接口消息共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为空对象。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 设置工作模式

飞机设置喊话器的工作模式（TTS 文字转语音 / voice 语音文件）。负载更新工作模式后在响应中返回处理结果。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0

```json
{
  "seq": 1,
  "method": "speaker_set_work_mode",

}
```

- **Topic**：`thing/product/{client_id}/services_reply`

```json
}
```

### 响应字段说明

飞机开始向负载传输音频文件，声明文件类型、uuid、文件名与解码码率。负载创建临时文件并进入传输态后在响应中返回处理结果。

对应功能介绍：<a href="../function-set/speaker.html#开始音频传输" target="_blank" rel="noopener noreferrer">开始音频传输</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`speaker_trans_start`
- **对应接口**：`SpeakerImpl_OnTransStart()`

```json
{
  "seq": 6,
  "method": "speaker_trans_start",
  "data": {
    "file_type": 1,
    "uuid": "1a2b3c4d",
    "file_name": "alarm.opus",
```

## 传输音频数据包

飞机逐包向负载传输音频二进制数据。data 字段为 hex 字符串编码，负载侧 SDK 自动解码为二进制；负载在回调中按 offset 写入文件。

对应功能介绍：<a href="../function-set/speaker.html#传输音频数据包" target="_blank" rel="noopener noreferrer">传输音频数据包</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`speaker_trans_data`
- **对应接口**：`SpeakerImpl_OnTransData()`

```json
{
  "seq": 7,
  "method": "speaker_trans_data",
  "data": {
    "packet_index": 0,
    "offset": 0,
    "data": "deadbeef"
  }
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| packet_index | integer | 是 | 包序号。 |
| offset | integer | 是 | 本包在文件中的字节偏移。 |
| data | string | 是 | 本包音频二进制数据，以 hex 字符串编码。 |

:::warning 注意：
data 字段为 hex 字符串，负载侧 SDK 会自动将其解码为二进制。负载回调中收到的是已解码的二进制数据，无需再做 hex 解码。
:::

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：负载 → 飞机

```json
{
  "seq": 7,
  "method": "speaker_trans_data",
  "data": {
    "result": 0,
    "result_message": "success"
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 内无接口特有字段。
