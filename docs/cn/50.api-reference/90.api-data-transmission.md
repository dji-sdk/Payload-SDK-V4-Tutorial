本章节定义数据传输功能的 MQTT 接口，涵盖负载发送数据、负载接收数据的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/data-transmission.html" target="_blank" rel="noopener noreferrer">功能集合-数据传输</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| event 发送 | 负载 → 飞机 | `thing/product/{client_id}/events` |
| event 接收 | 飞机 → 负载 | `thing/product/{client_id}/events` |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| `custom_small_data_transmit_req` | event | 负载向目标设备发送数据 | `CustomSmallData_PublishTransmit()` |
| `custom_small_data_transmit_event` | event | 负载接收其他负载或云端发来的数据 | `CustomSmallData_OnTransmitPush()` |

:::warning 注意：
发送与接收使用不同的 method：发送用 `custom_small_data_transmit_req`，接收用 `custom_small_data_transmit_event`；飞机端据此区分路由方向，不可混用。event 采用 fire-and-forget 语义，无 `services_reply` 应答。
:::

## 公共参数

以下参数为数据传输各接口消息共用的顶层通用参数，各接口的字段说明中不再重复列出。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 消息序列号。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体。 |

## 发送数据

负载向指定目标设备发送一条小数据。数据经飞机路由转发至目标设备。

对应功能介绍：<a href="../function-set/data-transmission.html#发送数据" target="_blank" rel="noopener noreferrer">发送数据</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/events`
- **方向**：负载 → 飞机
- **QoS**：0
- **method**：`custom_small_data_transmit_req`
- **对应接口**：`CustomSmallData_PublishTransmit()`

```json
{
  "seq": 1,
  "method": "custom_small_data_transmit_req",
  "data": {
    "target": 15,
    "payload": "aGVsbG8gY2xvdWQ="
  }
}
```

### 字段说明

顶层字段见 [公共参数](#公共参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| target | integer | 是 | 目标设备通道地址。<ul><li>1：负载 1 号位</li><li>2：负载 2 号位</li><li>3：负载 3 号位</li><li>15：云端</li></ul> |
| payload | string | 是 | 透传数据，原始字节经 Base64 编码后的字符串，解码后最大 256 字节。 |

## 接收数据

其他负载或云端发来的数据经飞机转发后推送给负载。

对应功能介绍：<a href="../function-set/data-transmission.html#接收数据" target="_blank" rel="noopener noreferrer">接收数据</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/events`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`custom_small_data_transmit_event`
- **对应接口**：`CustomSmallData_OnTransmitPush()`

```json
{
  "seq": 2,
  "method": "custom_small_data_transmit_event",
  "data": {
    "source": 1,
    "payload": "cnRvcyBhY2sgIzA="
  }
}
```

### 字段说明

顶层字段见 [公共参数](#公共参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| source | integer | 是 | 数据来源，即该透传数据的发出设备。<ul><li>1：负载 1 号位</li><li>2：负载 2 号位</li><li>3：负载 3 号位</li><li>15：云端</li></ul> |
| payload | string | 是 | 透传数据，原始字节经 Base64 编码后的字符串，解码后最大 256 字节。 |
