本章节定义电源管理（Power）功能的 MQTT 接口，涵盖关机通知的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/power-management.html" target="_blank" rel="noopener noreferrer">功能集合-电源管理</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | Topic |
|:---|:---|
| service 请求 | thing/product/{client_id}/services |
| service 响应 | thing/product/{client_id}/services_reply |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

接口方向见对应小节：

| method | 类型 | 用途 | 方向 | 对应 C 接口 |
|:---|:---|:---|:---|:---|
| power_off_notification | service | 飞机通知负载准备下电 | 飞机 → 负载 | PowerImpl_OnPowerOffNotification() |

## 公共参数

以下参数为电源管理各接口请求与响应共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为 `{}`。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 关机通知

飞机通知负载即将下电。负载在响应中返回是否已准备好下电。

对应功能介绍：<a href="../function-set/power-management.html#响应关机通知" target="_blank" rel="noopener noreferrer">响应关机通知</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`power_off_notification`
- **对应接口**：`PowerImpl_OnPowerOffNotification()`

```json
{
  "seq": 2,
  "method": "power_off_notification",
  "data": {}
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 固定为空对象 `{}`。

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：负载 → 飞机

```json
{
  "seq": 2,
  "method": "power_off_notification",
  "data": {
    "result": 0,
    "result_message": "success",
    "preparation_flag": true
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| preparation_flag | boolean | 是 | 是否已准备好下电。<ul><li>false：未准备好下电</li><li>true：已准备好下电</li></ul> |
