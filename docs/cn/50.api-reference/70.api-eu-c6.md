本章节定义 EFTS（Emergency Flight Termination System，应急飞行终止系统）功能的 MQTT 接口，涵盖使能负载 PWM 触发口、查询 FTS PWM 触发状态的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/eu-c6.html" target="_blank" rel="noopener noreferrer">功能集合-紧急降落</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| service 请求 | 负载 → 飞机 | thing/product/{client_id}/services |
| service 响应 | 飞机 → 负载 | thing/product/{client_id}/services_reply |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| efts_select_pwm_trigger | service | 使能负载侧 PWM 触发口 | Efts_SelectFtsPwmTrigger() |
| efts_get_trigger_status | service | 查询 FTS PWM 触发状态 | Efts_GetFtsTriggerStatus() |

## 公共参数

以下参数为所有 EFTS 接口请求与响应共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为 `{}`。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 使能 PWM 触发口

使能负载侧的 PWM 触发口。本接口仅使能触发口，不输出 PWM 信号，也不执行停桨动作；使能后，由外部 PWM 硬件向该端口输出符合规格的 PWM 信号，触发飞行平台停桨。本接口应在飞机处于地面（已落地）状态时调用。

对应功能介绍：<a href="../function-set/eu-c6.html#使能-fts-pwm-触发口" target="_blank" rel="noopener noreferrer">使能 FTS PWM 触发口</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：负载 → 飞机
- **QoS**：0
- **method**：`efts_select_pwm_trigger`
- **对应接口**：`Efts_SelectFtsPwmTrigger()`

```json
{
  "seq": 1,
  "method": "efts_select_pwm_trigger",
  "data": {}
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 固定为空对象 `{}`。

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：飞机 → 负载

```json
{
  "seq": 1,
  "method": "efts_select_pwm_trigger",
  "data": {
    "result": 0,
    "result_message": "success"
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 内无接口特有字段。

## 查询 FTS PWM 触发状态

查询当前 FTS PWM 触发状态及累计正确接收到的 PWM 停桨信号次数。如需确认停桨执行效果，可同时订阅飞控 ESC 数据，通过电调转速进行校验。

对应功能介绍：<a href="../function-set/eu-c6.html#查询-fts-pwm-触发状态" target="_blank" rel="noopener noreferrer">查询 FTS PWM 触发状态</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：负载 → 飞机
- **QoS**：0
- **method**：`efts_get_trigger_status`
- **对应接口**：`Efts_GetFtsTriggerStatus()`

```json
{
  "seq": 2,
  "method": "efts_get_trigger_status",
  "data": {}
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 固定为空对象 `{}`。

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：飞机 → 负载

```json
{
  "seq": 2,
  "method": "efts_get_trigger_status",
  "data": {
    "result": 0,
    "result_message": "success",
    "fts_status": 1,
    "fts_pwm_cnt": 5
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| fts_status | integer | 是 | FTS PWM 触发状态。<ul><li>0：未触发</li><li>1：已触发</li></ul> |
| fts_pwm_cnt | integer | 是 | 累计正确接收到的 PWM 停桨信号次数。 |
