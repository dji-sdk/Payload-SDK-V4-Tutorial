本章节定义数据订阅（Data Subscription）功能的 MQTT 接口，涵盖订阅主题、取消订阅、查询最新值与飞控数据推送的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/fc-subscription.html" target="_blank" rel="noopener noreferrer">功能集合-数据订阅</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| service 请求 | 负载 → 飞机 | thing/product/{client_id}/services |
| service 响应 | 飞机 → 负载 | thing/product/{client_id}/services_reply |
| osd 推送 | 飞机 → 负载 | thing/product/{client_id}/osd |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| fc_subscribe_topic | service | 负载订阅指定主题并设置推送频率 | DataSubscription_SubscribeTopic() |
| fc_unsubscribe_topic | service | 负载取消指定主题的订阅 | DataSubscription_UnsubscribeTopic() |
| fc_get_latest_value | service | 负载查询指定主题的最新值 | DataSubscription_GetLatestValue() |
| fc_publish_data | osd | 飞控向负载推送已订阅主题的数据 | DataSubscription_OnPublishData() |

:::warning 注意：
`fc_get_latest_value` 的查询结果在 service 响应（services_reply）的 `data` 中返回；查询前须先订阅对应主题。批量订阅大量主题时应分批发送、控制发送节奏，避免短时间内大量请求积压导致订阅失败或超时。
:::

## 公共参数

以下参数为数据订阅各接口消息共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为 `{}`。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 订阅主题

负载订阅指定飞控遥测主题并设置推送频率。订阅成功后，飞控按 `frequency` 频率推送该主题数据。对同一主题重复订阅可更新频率，新频率覆盖旧订阅。

对应功能介绍：<a href="../function-set/fc-subscription.html#订阅主题" target="_blank" rel="noopener noreferrer">订阅主题</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：负载 → 飞机
- **QoS**：0
- **method**：`fc_subscribe_topic`
- **对应接口**：`DataSubscription_SubscribeTopic()`

```json
{
  "seq": 1,
  "method": "fc_subscribe_topic",
  "data": {
    "topic": "quaternion",
    "frequency": 10
  }
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| topic | string | 是 | 主题名，取值见 [订阅主题一览](#订阅主题一览)，如 `quaternion`。 |
| frequency | integer | 是 | 飞控推送该主题数据的频率，单位 Hz。<ul><li>1：1 Hz</li><li>5：5 Hz</li><li>10：10 Hz</li><li>50：50 Hz</li></ul> |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：飞机 → 负载

```json
{
  "seq": 1,
  "method": "fc_subscribe_topic",
  "data": {
    "result": 0,
    "result_message": "success"
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 内无接口特有字段。

## 飞控数据推送

飞控按各主题的订阅频率推送数据，不同主题分属不同消息。每条消息的 `data` 内仅包含当前主题对应的 key。

对应功能介绍：<a href="../function-set/fc-subscription.html#接收推送数据" target="_blank" rel="noopener noreferrer">接收推送数据</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/osd`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`fc_publish_data`
- **对应接口**：`DataSubscription_OnPublishData()`

以下示例为 `velocity`（速度）主题的一条推送消息；实际推送的 key 取决于当前推送的主题。

```json
{
  "seq": 100,
  "method": "fc_publish_data",
  "data": {
    "velocity": { "x": 0.1, "y": -0.2, "z": 0.0, "health": 1 }
  }
}
```
