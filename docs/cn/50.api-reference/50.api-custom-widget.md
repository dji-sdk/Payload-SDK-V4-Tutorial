本章节定义自定义控件（Widget）功能的 MQTT 接口，涵盖获取控件文件列表、设置控件值、读取控件值与控件状态推送、浮窗消息推送的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/custom-widget.html" target="_blank" rel="noopener noreferrer">功能集合-自定义控件</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| service 请求 | 飞机 → 负载 | thing/product/{client_id}/services |
| service 响应 | 负载 → 飞机 | thing/product/{client_id}/services_reply |
| state 推送 | 负载 → 飞机 | thing/product/{client_id}/state |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| widget_get_file_list | service | 飞机获取控件配置文件列表 | WidgetImpl_OnGetFileList() |
| widget_set_value | service | 飞机设置控件值 | WidgetImpl_OnSetValue() |
| widget_get_value | service | 飞机读取控件值 | WidgetImpl_OnGetValue() |
| widget_state | state | 负载推送控件状态 | Widget_PublishState() |
| widget_float_window_msg | state | 负载推送浮窗消息 | Widget_PublishFloatWindowMsg() |

## 公共参数

以下参数为自定义控件各接口消息共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为 `{}`。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 获取控件文件列表

飞机按 APP 当前语言与屏幕类型向负载请求控件配置文件列表；负载在响应中返回，飞机可据 `md5` 判断是否需要下载更新。

对应功能介绍：<a href="../function-set/custom-widget.html#获取控件文件列表" target="_blank" rel="noopener noreferrer">获取控件文件列表</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`widget_get_file_list`
- **对应接口**：`WidgetImpl_OnGetFileList()`

```json
{
  "seq": 1,
  "method": "widget_get_file_list",
  "data": {
    "language": 1,
    "screen_type": 0
  }
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| language | integer | 是 | APP 当前系统语言类型。<ul><li>0：英语</li><li>1：中文简体</li><li>2：日语</li><li>3：法语</li></ul> |
| screen_type | integer | 是 | APP 当前屏幕类型。<ul><li>0：大屏</li><li>1：小屏</li></ul> |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：负载 → 飞机

```json
{
  "seq": 1,
  "method": "widget_get_file_list",
  "data": {
    "result": 0,
    "result_message": "success",
    "file_list": [
      {
        "file_index": 0,
        "file_name": "widget_config.json",
        "file_size": 2048,
        "md5": "9e107d9d372bb6826bd81d3542a419d6"
      }
    ]
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 字段说明如下：

<div class="collapsible" />

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| file_list | array&lt;object&gt; | 是 | 控件配置文件列表。 |
| >>file_index | integer | 是 | 文件索引。 |
| >>file_name | string | 是 | 文件名，如 `widget_config.json`。 |
| >>file_size | integer | 是 | 文件大小，单位字节。 |
| >>md5 | string | 是 | 文件 MD5，用于校验与判断是否需要更新。 |

## 设置控件值

飞机设置指定控件的值。负载更新控件状态后在响应中返回处理结果。

对应功能介绍：<a href="../function-set/custom-widget.html#设置控件值" target="_blank" rel="noopener noreferrer">设置控件值</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：飞机 → 负载
- **QoS**：0
- **method**：`widget_set_value`
- **对应接口**：`WidgetImpl_OnSetValue()`

```json
{
  "seq": 2,
  "method": "widget_set_value",
  "data": {
    "widget_index": 2,
    "widget_type": 2,
    "widget_value": 1
  }
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| widget_index | integer | 是 | 控件索引。 |
| widget_type | integer | 是 | 控件类型。<ul><li>1：Button（按钮）</li><li>2：Switch（开关）</li><li>3：Scale（滑动条）</li><li>4：List（列表）</li><li>5：IntInputBox（整数输入框）</li></ul> |
| widget_value | integer | 是 | 控件值。 |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：负载 → 飞机

```json
{
  "seq": 2,
  "method": "widget_set_value",
  "data": {
    "result": 0,
    "result_message": "success"
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 内无接口特有字段。
