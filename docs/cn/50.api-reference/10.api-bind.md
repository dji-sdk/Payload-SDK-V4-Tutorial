本章节定义应用绑定（Bind）功能的 MQTT 接口，涵盖 `bind_required` 事件的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/bind.html" target="_blank" rel="noopener noreferrer">功能集合-绑定状态通知</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| event 推送 | 飞机端 → 负载 | thing/product/{client_id}/events |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| bind_required | event | 飞机端通知设备未绑定，需通过 DJI Assistant 2 完成绑定 | bind_monitor_start() 订阅后接收 |

## 公共参数

### 事件推送参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 消息序列号。 |
| method | string | 是 | 固定为 `bind_required`。 |
| data | object | 是 | 业务数据主体，见各接口字段说明。 |

## bind_required 事件

飞机端检测到设备未绑定时，在事件通道主动推送 `bind_required`，携带当前绑定状态、状态描述及操作提示，通知负载通过 DJI Assistant 2 完成绑定流程。设备连接 MQTT 服务器后如处于未绑定状态，飞机端会持续推送此事件直至绑定完成。推送期间，飞机端通常会拒绝负载发起的所有 service 请求。

对应功能介绍：<a href="../function-set/bind.html#启动监听" target="_blank" rel="noopener noreferrer">启动监听</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/events`
- **方向**：飞机端 → 负载
- **QoS**：0
- **method**：`bind_required`
- **对应接口**：`bind_monitor_start()` 订阅后被动接收

```json
{
  "seq": 0,
  "method": "bind_required",
  "data": {
    "bind_state": 3,
    "bind_state_desc": "BINDING",
    "message": "Binding in progress. Waiting for DA2 to complete binding.",
    "timestamp_ms": 1716393600000
  }
}
```

### 字段说明

顶层字段见 [事件推送参数](#事件推送参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| bind_state | integer | 是 | 当前绑定状态。<ul><li>0：空闲，尚未开始绑定检查</li><li>1：正在查询绑定状态</li><li>2：已绑定</li><li>3：绑定中，正在等待 DJI Assistant 2 完成绑定</li><li>4：绑定成功</li><li>5：绑定失败</li><li>6：正在等待 DJI Assistant 2 完成解绑</li><li>7：解绑成功</li><li>8：解绑失败</li></ul> |
| bind_state_desc | string | 是 | 绑定状态描述字符串，如 "BINDING"。 |
| message | string | 是 | 操作提示信息，如 "Binding in progress. Waiting for DJI Assistant 2 to complete binding."。 |
| timestamp_ms | integer | 是 | 飞机端发送时间戳，单位毫秒。 |
