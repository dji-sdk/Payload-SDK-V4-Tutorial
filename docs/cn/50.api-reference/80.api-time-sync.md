本章节定义时间同步（Time Sync）功能的 MQTT 接口，涵盖设置信号模式与 UTC 时间推送的 payload 结构与字段说明。

:::tip 说明：
- PSDK 中的 C 接口是对本章节 MQTT 协议的封装。使用 PSDK 开发时，无需直接操作 MQTT 报文；如需自行实现协议对接，或对底层消息进行调试验证，可参照本章节的协议定义。功能介绍与 C 接口调用示例详见 <a href="../function-set/time-sync.html" target="_blank" rel="noopener noreferrer">功能集合-时间同步</a>。
- 使用本功能前，负载设备需先完成接入与鉴权，接入协议详见 <a href="api-access-authentication.html" target="_blank" rel="noopener noreferrer">接入与鉴权</a>。
:::

## 协议说明

接口涉及的 Topic 如下：

| 类型 | 方向 | Topic |
|:---|:---|:---|
| service 请求 | 负载 → 飞机 | thing/product/{client_id}/services |
| service 响应 | 飞机 → 负载 | thing/product/{client_id}/services_reply |
| event 推送 | 飞机端 → 负载 | thing/product/{client_id}/events |

- `{client_id}` 为负载设备序列号（device sn）。
- **QoS**：0。

本模块支持的接口如下：

| method | 类型 | 用途 | 对应 C 接口 |
|:---|:---|:---|:---|
| time_sync_set_signal_mode | service | 负载设置时间同步信号模式（FTS/PPS） | TimeSync_SetSignalMode() |
| time_sync | event | 飞机端向负载推送 UTC 时间 | TimeSync_OnSync() |

:::warning 注意：
UTC 时间仅在信号模式为 PPS 时由飞机端推送。负载调用 `time_sync_set_signal_mode` 将模式设为 PPS 后，飞机端开始通过 `time_sync` event 上报 UTC 时间。上报 UTC 时间的 event method 为 `time_sync`，与设置信号模式的 service method `time_sync_set_signal_mode` 相互区分。
:::

## 公共参数

以下参数为时间同步各接口消息共用的顶层通用参数，各接口的字段说明中不再重复列出。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| seq | integer | 是 | 请求序列号；响应原样回显，用于请求与响应匹配。 |
| method | string | 是 | 方法标识，取值见各接口说明。 |
| data | object | 是 | 业务数据主体；无业务参数时为 `{}`。 |

### 响应参数

响应顶层字段与请求一致。`data` 默认包含以下公共字段；接口特有字段见对应小节。

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| result | integer | 是 | 处理结果。<ul><li>0：成功</li><li>非 0：失败</li></ul> |
| result_message | string | 是 | 结果描述信息。 |

## 设置时间同步信号模式

负载设置时间同步信号源。选择 PPS 后，飞机端开始按周期推送 UTC 时间；选择 FTS（默认）后停止推送。

对应功能介绍：<a href="../function-set/time-sync.html#设置时间同步信号模式" target="_blank" rel="noopener noreferrer">设置时间同步信号模式</a>。

### 请求 Payload 示例

- **Topic**：`thing/product/{client_id}/services`
- **方向**：负载 → 飞机
- **QoS**：0
- **method**：`time_sync_set_signal_mode`
- **对应接口**：`TimeSync_SetSignalMode()`

```json
{
  "seq": 1,
  "method": "time_sync_set_signal_mode",
  "data": {
    "mode": 1
  }
}
```

### 请求字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| mode | integer | 是 | 时间同步信号模式。<ul><li>0：FTS 信号（默认）</li><li>1：PPS 信号</li></ul> |

### 响应 Payload 示例

- **Topic**：`thing/product/{client_id}/services_reply`
- **方向**：飞机 → 负载

```json
{
  "seq": 1,
  "method": "time_sync_set_signal_mode",
  "data": {
    "result": 0,
    "result_message": "success"
  }
}
```

### 响应字段说明

顶层字段见 [响应参数](#响应参数)，`data` 内无接口特有字段。

## 接收 UTC 时间

信号模式为 PPS 时，飞机端按周期推送当前 UTC 时间。

对应功能介绍：<a href="../function-set/time-sync.html#接收-utc-时间" target="_blank" rel="noopener noreferrer">接收 UTC 时间</a>。

### Payload 示例

- **Topic**：`thing/product/{client_id}/events`
- **方向**：飞机端 → 负载
- **QoS**：0
- **method**：`time_sync`
- **对应接口**：`TimeSync_OnSync()`

```json
{
  "seq": 1,
  "method": "time_sync",
  "data": {
    "year": 2021,
    "month": 1,
    "day": 1,
    "hour": 2,
    "minute": 0,
    "second": 0,
    "nano_second": 0
  }
}
```

### 字段说明

顶层字段见 [请求参数](#请求参数)，`data` 字段说明如下：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| year | integer | 是 | 年。 |
| month | integer | 是 | 月，取值 1~12。 |
| day | integer | 是 | 日，取值 1~31。 |
| hour | integer | 是 | 小时，取值 0~23。 |
| minute | integer | 是 | 分钟，取值 0~59。 |
| second | integer | 是 | 秒，取值 0~59。 |
| nano_second | integer | 是 | 纳秒，取值 0~999999999。 |
