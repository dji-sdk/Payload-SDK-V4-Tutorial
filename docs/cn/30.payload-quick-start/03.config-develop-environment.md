### 资源占用对比
#### Linux
使用 Manifold 3 运行 Linux 平台 PSDK 示例程序，程序运行时的资源占用情况如下所示：
* 栈：约 135,168 字节
* 堆：约 270,336 字节
* Text 段：1,409,889 字节
* Data 段：19,532 字节
* Bss 段：20,344 字节
* CPU 占用：7.2 %

#### RTOS
使用 GD32F527ZMT7 运行 RTOS 平台 PSDK 示例程序，程序运行时的资源占用情况如下所示：
* Text 段：281,880 字节
* Data 段：892 字节
* Bss 段：521,176 字节
* RAM 消耗：142,000 字节
* CPU 占用：24%

## 配置环境
请根据已选系统平台阅读对应小节。

### 配置 Linux 开发环境
Payload SDK 基于 **MQTT 协议**，提供 C 客户端代码，通过 MQTT broker 与飞行平台通信。开发负载设备前，请先准备如下工具与依赖。

#### 安装编译工具

| 工具 | 最低版本 | 用途 | Ubuntu / Debian 安装命令 |
|:---|:---|:---|:---|
| GCC host 编译器 | - | 编译本机 host demo | `sudo apt install build-essential` |
| aarch64-linux-gnu-gcc | 9 | 交叉编译 arm64 负载 demo | `sudo apt install gcc-aarch64-linux-gnu` |
| CMake | 3.13 | 构建系统 | `sudo apt install cmake` |
| OpenSSL headers | - | TLS 与 HMAC（host headers 跨 arch 通用） | `sudo apt install libssl-dev` |
| Mosquitto headers | - | MQTT 通信（传输层） | `sudo apt install libmosquitto-dev` |
| cJSON headers | - | JSON 编解码 | `sudo apt install libcjson-dev` |

> 说明：
> - 仓库不再随包 vendored 预编译库，交叉编译时需要 host 提供 OpenSSL / mosquitto / cJSON 头文件；目标机运行时再安装对应架构的运行时库。
> - FFmpeg 不再是示例的必需依赖；喊话器/媒体相关功能请按具体业务文档补充。

### 配置 RTOS 开发环境

GD32F527 为 Cortex-M33 内核，需使用 ARM Compiler 6（Armclang）编译，不支持 ARM Compiler 5（Armcc）。

其中 C 编译器为核心工具，推荐使用 Armclang.exe V6.12。完整开发环境配置建议如下：

| 项目 | 版本 |
|:---|:---|
| Keil MDK-ARM | 5.27.1 |
| C Compiler | Armclang.exe V6.12 |
| Assembler | Armasm.exe V6.12（随 Armclang 集成） |
| Linker | Armlink.exe V6.12 |
| CMSIS Core | 5.5.1 |
| Device Family Pack | GigaDevice.GD32F527_DFP 1.4.0 |

安装 [Keil MDK](http://www2.keil.com/mdk5/) 后，激活软件，并在 [兆易创新官网](https://www.gd32mcu.com/cn/download?kw=f527&lan=cn) 手动下载最新的 GD32F527 AddOn 包并安装，完成上表所列 Device Family Pack 的配置。
