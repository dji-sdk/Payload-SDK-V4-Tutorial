## E-Port V3 接口

Matrice 5TD 机身提供 E-Port V3 接口，用于连接第三方 PSDK 负载设备。

<div>
<div align=center>
<img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk-iot/demo/EPort_V3_Port.png" style="width:80%"/>
<div style="text-align: center"><p>图. Matrice 5TD E-Port V3 接口</p></div>
</div></div>

Matrice 5TD 的 E-Port V3 接口均支持连接负载设备，其中 E1 为高速接口（支持 USB 3.0），E2/E3 为低速接口（支持 USB 2.0）。

:::tip 说明：
- Matrice 5TD 的负载口上电后先输出 5V 低压，飞行器识别到接入的是第三方负载后会自动输出高压（15V-25.8V），开发者无需主动申请。飞行器先等待负载完成 USB 枚举，若约 6s 后仍未检测到枚举，则转为查询 SDK 认证芯片。详见 <a href="./payload-develop-criterion.html#高压输出触发机制" target="_blank" rel="noopener noreferrer">高压输出触发机制</a>。
- 当前仅支持一种 USB 枚举方式：外部设备实现 USB RNDIS 模式，VID:PID 设置为 `2CA3:F004`。
:::
