### 高压输出触发机制

::: warning 注意：
本节仅适用于 **Matrice 5TD**。
:::

负载接口上电后默认输出 5V 低压。飞行器需先确认接入的是合法的第三方负载，才会将接口切换为高压（15V-25.8V）输出。该过程由飞行器自动完成，**开发者无需主动申请**。

飞行器按以下顺序识别负载：

1. **USB 枚举识别**：检测到负载接入后，飞行器等待负载完成 USB 枚举。负载若能在 5V 低压下启动，并按指定的第三方负载枚举信息与飞行器建立 USB 通信，飞行器即判定为第三方负载并输出高压。该路径的耗时取决于负载自身的 USB 就绪时间，通常更短。
2. **加密芯片识别**：若约 6s 后仍未检测到 USB 枚举，飞行器转为通过 I2C 查询官方加密芯片，查询到合法芯片后输出高压。查询通常耗时 100ms~2s，极端情况下可达 12s。

Matrice 5TD 必须使用 E-Port V3 同轴线接入负载，该同轴线内置 SDK 认证芯片，**开发者无需自行集成认证芯片**，只需完成 <a href="../app-bind.html" target="_blank" rel="noopener noreferrer">应用绑定</a> 即可。若负载无法在 5V 低压下完成启动与 USB 枚举，飞行器会通过同轴线内置的认证芯片完成识别并输出高压。

### 供电约束

::: warning 注意：
本约束仅适用于 **Matrice 5TD** 的 **E2、E3 低速接口**，其他机型及接口不涉及。
:::

低速口的供电电压 VBUS 在上电过程中会先稳定在 5V，随后再切换至高压档位（20V）。配件端需根据该上电及电压切换时序设计后级电源与负载的使能逻辑。为保证配件正常工作并避免器件损坏，三方配件在设计供电方案时须遵循以下约束：

1. **5V 档位负载能力**：低速口在 5V 档位下的负载能力为 **5V / 1A**，配件在该档位下的总电流不得超过 1A。超额取电会触发过流保护，导致本架次该接口不再供电。
2. **后级器件的上电时序**：接于低速口 5V（VBUS_5V）之后的后级电源及负载器件，须在 VBUS_5V 建立稳定（即 5V 档位上电完成）后至少 **10ms** 再使能并开始工作。若后级器件上电过早，可能破坏配件自身的上电时序，影响功能正常运行。
3. **电压切换阶段的负载限制**：在 VBUS 由 5V 向 20V 切换的过程中，不得使能高功率负载器件，须确保该阶段低速口的总电流不超过 1A；待电压切换完成、20V 建立稳定后，方可使能高功率负载。

::: danger 注意：
若在电压切换过程中提前使能高功率负载、导致电流超过 1A，可能影响负载功能正常运行，由此造成的问题不在保修范围内。
:::

## 结构设计标准

::: tip 说明:

* 为避免搭载在无人机上的负载设备受无人机飞行惯性的影响，撞击电池仓和桨叶，损毁无人机或负载设备，请合理地设计负载设备的尺寸。

:::
