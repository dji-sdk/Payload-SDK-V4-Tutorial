## Matrice 5TD 设备连接

开始 Matrice 5TD 的设备连接前，请先阅读 Matrice 5TD 用户手册中的 "部件名称" 并关注飞行器组件的介绍。Matrice 5TD 支持通过 E-Port V3 接口连接飞行器与负载设备。

### 基于 E-Port V3 接口连接设备

Matrice 5TD 的 E-Port V3 接口均支持连接负载设备，其中 E1 为高速接口（支持 USB 3.0），E2/E3 为低速接口（支持 USB 2.0）。下图以连接 E3 低速接口为例；如需使用高速数据能力，请连接 E1 高速接口。接口说明请参见 <a href="./drone-port.html#e-port-v3-接口" target="_blank" rel="noopener noreferrer">E-Port V3 接口</a>。

使用 E-Port V3 同轴线将 E-Port V3 开发板连接至 Matrice 5TD 的 E-Port V3 接口。具体步骤如下：

1. 将 E-Port V3 开发板上的 E-Port V2/V3 切换开关拨至 "E-PORT V3" 端。
2. 将 E-Port V3 开发板的 ENABLE 开关拨到 "ON"，SWITCH 开关拨到 "ONBOARD" 端（板载 GD32 开发用 "ONBOARD"，外接开发板用 "EXPAND"，详见下方说明）。
3. 使用 E-Port V3 同轴线连接 E-Port V3 开发板与 Matrice 5TD 机身的 E-Port V3 接口。
4. 无人机整机启动，检查 E-Port V3 开发板绿色电源指示灯是否亮起。

按照上述步骤完成连接后，用户可直接基于 E-Port V3 开发板上自带的 GD32 进行 PSDK 开发；若需外接第三方开发板（如树莓派），则将 SWITCH 开关拨到 "EXPAND" 端，通过 E-Port V3 开发板的 USB 接口连接外部设备开发。
