## 概述

应用绑定（Bind）用于建立**负载设备与飞行平台之间的身份授权关系**。负载设备接入 MQTT broker 后，只有在完成绑定、获得授权的前提下，飞机端才会放行业务请求。

绑定动作由飞手通过 DJI Assistant 2 完成。完成绑定后，当负载设备挂载在无人机上时，负载设备将自动运行开发者编译或烧录的示例程序。

:::warning 注意：
应用绑定是业务功能的前置条件。设备未绑定时，飞机端会拒绝业务请求；负载上线后应先确认绑定状态，再启动控件、喊话器等业务功能。
:::

## 是否需要应用绑定

是否需要应用绑定取决于负载的**接入方式**：通过**带认证芯片**的方式接入（如 E-Port V3 同轴线、SkyPort 等转接环）时需要绑定；不使用认证芯片的直连式负载（如妙算 3）则无需绑定。当前已支持的接入方式如下（后续新增机型 / 开发套件时会持续更新）：

<table class="col-1-left col-2-left col-3-left">
  <thead>
    <tr>
      <th>接入方式</th>
      <th>典型开发套件 / 负载</th>
      <th>是否需要应用绑定</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>E-Port V3 同轴线（含认证芯片）</td>
      <td>E-Port V3 开发套件（GD32F527 等）</td>
      <td>需要</td>
    </tr>
    <tr>
      <td>直连式（无认证芯片）</td>
      <td>妙算 3 应用</td>
      <td>不需要</td>
    </tr>
  </tbody>
</table>

:::tip 说明：
若不确定所用负载是否需要绑定，可在 DJI Assistant 2 的 “Payload SDK” 界面查看是否存在 “绑定” 入口，或联系 DJI 技术支持确认。
:::

## 应用绑定操作流程

:::tip 说明：
* 使用 DJI Assistant 2 绑定或调试负载设备时，请先在软件右上角的 “配置” 标签中打开 **“数据授权”** 开关，否则 DJI Assistant 2 将无法正常绑定或调试负载设备。
* 仅首次在无人机上使用时需进行应用绑定，后续在不同的无人机上使用时，无需重新绑定。
:::

1. 将负载设备开发板（如 GD32F527ZMT7）挂载在 DJI 无人机上，同时将 DJI 无人机连接到计算机。
2. 使用**应用信息**中的**账号**登录 DJI Assistant 2，单击 “Payload SDK” 选项卡，进入 PSDK 硬件平台界面。
3. 在 PSDK 硬件平台界面，单击 “绑定” 按钮，绑定硬件平台、示例程序与 DJI 无人机。
4. 绑定成功后，PSDK 硬件平台界面中的绑定状态将显示为 `已绑定`，如下图所示。

5. 应用绑定成功后，负载设备将被允许使用 PSDK 功能。

## 运行 Demo 前的确认

完成上述绑定后，运行 Demo 前请确认：

1. 负载设备已通过鉴权成功接入 broker。
2. 飞手已通过 DJI Assistant 2 完成设备绑定。
3. Demo 程序监听绑定状态，确认 `bind_state` 为已绑定后再启动业务功能。

绑定状态通知与查询的 C 接口用法、代码示例详见 <a href="../function-set/bind.html" target="_blank" rel="noopener noreferrer">功能集合-绑定状态通知</a>，底层 MQTT 协议详见 <a href="../api-reference/api-bind.html" target="_blank" rel="noopener noreferrer">协议参考-绑定状态通知</a>。
